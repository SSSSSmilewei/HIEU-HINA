## 1. 目标与验收

一个对程序设计完全没有认知的人，只用这个平台就能完整学完 CS61A 并基本掌握：看课、读讲义、评论、用 AI 问答解决难点、做完作业、交上最终项目，所有代码都在自己的仓库里。CS61A 是试点，跑通后照同一套做法铺到其他课。

验收分三层，前一层不过不验后一层。

**第一层：内容齐全**
- 每一讲：可换源的视频、站内中文讲义、幻灯片，视频和讲义能互相定位。
- 每一份 lab、homework、讨论课、项目：站内中文题面，每一题都能在站内写、运行、提交，看到 OJ 式的判题结果。
- 官方出现过的题型都有：写函数、预测输出（WWPD 和 ok 解锁）、环境图、多文件项目、SQL、Scheme、写测试 / 改错 / 代码填空。
- 没有「只有一个外链」的必学条目。

**第二层：能一站式走完**
- 从注册到交完最后一个项目不用离开平台；想在本地写的，用 VSCode 插件连自己的仓库。
- 卡住时：分级提示 → AI 问答 → 钉子提问，都带着当前的失败信息。
- 每一份作业的代码都在学员自己的仓库里，有提交历史，能整个拿走。

**第三层：真的学会了**
- 零基础试学：2–3 名没学过编程的新同学只用平台学前三周，记下每处卡住的地方，逐条修。
- 考核：官方考试改编成限时测验，结课测验及格线默认 70%（可改）。

## 2. 用户与角色

**学生**
1. 获取信息：老师和管理员发布的学校、比赛等信息（现有，不动）。
2. 学习与作业：学 CSDIY 的课并完成作业（本期 CS61A）。
3. 项目开发：用 VSCode 插件连服务器上的 Forgejo 仓库做项目，数据安全，随时能拿走。
4. 刷题训练：独立的 OJ 刷题区，有排行榜。

**管理者**（老师、助教、管理员角色相同）
1. 维护课程、发布消息：作业包导入、出题、卡点看板。
2. 纳新、管理新同学：新同学自动开通仓库和 OJ。
3. 晚自习请假等信息：新增请假申请与审批。

## 3. 核心模型：一切回到仓库

| 来源 | 进仓库的方式 |
| --- | --- |
| OJ 刷题 | 通过后写入刷题仓库，按题号和专题归档 |
| 课程作业 | 每次提交判题时自动 commit 到这门课的仓库，提交说明自动写好 |
| 自己的项目 | VSCode 插件或 `git push` |
| 学校服务器上的项目 | 同样进自己的仓库 |

规矩：平台账号即仓库账号；仓库是真的 Git 仓库（文件树、历史、diff、clone、镜像 GitHub）；网页和本地是同一个仓库；作业仓库默认私有；每个仓库自动生成 README。

## 4. 统一做题界面与判题

- **一套做题界面**，OJ 和课程作业共用：左题目（题面、示例、约束、需要的知识、题解 / 讨论 / 提交记录标签）；右上 Monaco 编辑器（多文件标签、文件树）；右下终端（运行输出、判题结果、Python 交互）。
- **外观**：深色 IDE 风格、等宽字体、直角、信息密集，参考 LeetCode 做题页、VSCode、Codeforces；不用平台的圆角玻璃组件。
- **判题全在服务器**：判题服务（可替换后端，第一版用开源沙箱 go-judge），「运行」跑公开示例，「提交」跑全部测试。
- **结果**：通过、答案错误、超时、内存超限、运行错误、编译错误；用时、内存；第一个失败用例的输入 / 期望 / 实际。
- **AI 判断**：提交后 AI 读题面、代码和测试结果，给出思路、边界、质量的评语；不给答案。

## 5. CS61A 试点范围

以站内现有课程包为底（2026 春季：38 讲、13 讨论课、12 lab、11 homework、5 个项目条目、3 场考试）。起始代码与官方测试来源：`github.com/lr2933/cs61a-spring-2026`（学员整理的 2026 春季材料存档）。

功能：深海游戏地图入口；学习间（视频换源 + 讲义并排、幻灯片、理解检查、钉子、语音笔记、AI 问答）；作业台（统一做题界面、分级提示、AI 辅导、卡住检测）；过关（自动 commit、地图点亮、热力图、AI 评语）；复习（掌握度、错题间隔重复）；考核（限时测验）；VSCode 插件；管理端看板。

## 6. 作业包格式

见 `src/shared/problem.ts`（实现后为准）。一份作业 = 基本信息 + 题面 + 起始代码文件树（可改 / 只读）+ 仓库位置 + 题目列表；每题 = 题型、要改的位置、公开测试（官方 ok 原样）、限制、知识点、三级提示、讲解。不含参考解（决定 9）。

## 7. 综合排行算法

总分 = 作业分 × w1 + 项目分 × w2 + 刷题分 × w3（默认 0.3 / 0.4 / 0.3，管理者可调），细则见故事。作业和项目按完成度与 AI 质量评语计分，刷题按难度加权并对重复刷简单题递减；周榜、学期榜、总榜。
