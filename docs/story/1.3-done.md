# Story 1.3 — 平台判题接口与提交记录

## 主要目标
平台接住做题界面的请求，转给判题服务，存提交记录。

## 验收标准
- [x] D1 迁移（只加表）：`oj_submissions`（用户、题目、语言、文件、结果、用时、内存、明细、时间）
- [x] `POST /api/oj/run`、`POST /api/oj/submit`、`GET /api/oj/submissions?problem=`、`GET /api/oj/submissions/:id`
- [x] Worker 用环境变量 `JUDGE_URL`、`JUDGE_TOKEN` 调判题服务；本地 dev.ts 同样支持
- [x] 未登录：能运行，不能提交；提交需登录
- [x] 限流：每人每分钟 10 次提交
- [x] 通过的作业题记进课程进度和热力图

## 功能要点
- 请求体大小上限 256 KB
- 判题服务不可用时回 503 和中文提示，不吞错误
- 提交记录只本人和管理员可见

## 单元测试用例设计
- 参数校验：题目不存在 404、语言不在题目允许列表 400
- 限流计数
- 热力图记录只在第一次 AC 时写

## 行为测试用例设计
- 本地：登录后提交 lab01 某题，记录出现在列表里，再次打开能看到代码和结果
