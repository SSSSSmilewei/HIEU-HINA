# Story 1.4 — 做题界面（IDE 风格）

## 主要目标
像 LeetCode 做题页和 VSCode 一样的做题界面，课程作业和刷题共用。

## 验收标准
- [x] 路由：课程作业 `/courses/:slug/hw/:assignment/:problem`，刷题 `/oj/p/:id`；全屏布局，不套平台侧栏
- [x] 左：题面 / 题解讨论 / 提交记录 标签；右上：Monaco 编辑器（多文件标签、文件树、快捷键 Ctrl+Enter 运行、Ctrl+Shift+Enter 提交）；右下：终端面板（运行输出、判题结果、用例对比）
- [x] 三栏可拖动调整宽高，记住布局
- [x] 独立样式 `src/client/styles/ide.css`：深色为主（也有浅色）、等宽字体、直角、细分隔线、状态色，和平台的玻璃样式隔离
- [x] 代码自动存草稿（本地 + 登录后服务器），可恢复初始代码
- [x] 结果面板：verdict 大字、用时内存、逐用例列表、失败用例的输入/期望/实际对比

## 功能要点
- Monaco 用 npm 包本地打包，worker 作为单独入口构建，不从外网 CDN 加载
- Python / C / C++ / Java / SQL / Scheme 高亮
- 手机宽度：上下排列，编辑器可用

## 单元测试用例设计
- 布局状态读写（localStorage 读写失败不报错）
- 结果数据到界面状态的转换
