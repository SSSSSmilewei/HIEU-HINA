- 讨论课没有 zip 和 ok：起始代码取自页面的 activateEditor('…')，一题一个文件，补一个 .ok；用到 tree / Link / Tree 的题带一个只读的 cs61a_helpers.py（取自官方 lab05 的 tree.py 和 hw06 的类）。画环境图、口头讨论、用 Scheme 的 Pair / nil 的题不收；disc00、disc09–12 因此没有作业
- 判题：别的题的文件还没写完（语法错误）不连累这道题
- 来源：2026 春季（lr2933 存档，英文原文 + 我们的翻译）；2020 秋季（chillyhigh/CS61A-CN，MIT，社区翻译），作业编号 fa20-*，按主题对到 2026 春季的课程条目（`FA20_ITEM`）。期中复习 lab03、lab09 和 Scheme 的 hw06 不收

- 暂不导入（逐条列出）：lab00（装环境，没有可判的题）；lab08、lab10、hw07、hw08、hw09（Scheme）；lab11、hw10（SQL）→ 故事 3.4；hw11 没有起始代码；hw06 的期中问卷不是题，跳过
