# Story 2.3 — VSCode 插件

## 主要目标
在自己电脑上用 VSCode 写作业，提交到同一个仓库和 OJ。

## 验收标准
- [ ] `vscode/` 目录：插件源码；命令：登录、克隆我的课程仓库、运行公开测试、提交到 OJ、查看结果
- [ ] 提交 = git commit + push + 调平台提交接口，结果在 VSCode 面板显示
- [ ] 打包成 `.vsix`，平台「仓库」页提供下载

## 功能要点
- 登录用平台签发的个人令牌（可在平台撤销）

## 单元测试用例设计
- 令牌存储、接口封装

## 行为测试用例设计
- 本地装 .vsix，克隆仓库，改代码提交，平台提交记录出现这次提交
