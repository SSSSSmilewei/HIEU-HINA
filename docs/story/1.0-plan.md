# Story 1.0 — 总体规划：OJ 判题底座、仓库与 CS61A 试点

来源：`docs/prd/hiana-oj.md`。本文件是所有故事的总览（这一组故事编号 1–6 都以它为准）。

## 范围
- 一套做题界面 + 一套服务器判题，CS61A 作业和独立刷题 OJ 共用。
- 一切回到仓库：每次提交写进学员自己的 Forgejo 仓库。
- CS61A 2026 春季整门课：讲座、lab、homework、讨论课、项目、考试，全部题型。
- AI 接入：代码判断、分级提示、带上下文的问答。
- 独立刷题区与综合排行；晚自习请假；管理端看板。

## 架构（AI 定，负责人可改）
- 平台：现有 Cloudflare Worker + D1 + React（本地 `scripts/dev.ts`）。
- 判题服务 `judge/`：独立的 TypeScript 服务（bun 运行），部署在学校服务器；底层沙箱用开源 go-judge（Docker 镜像，Hydro 底下用的同一个）。平台只通过 HTTP + 令牌调用它，以后可换成 Hydro。
- 仓库：Forgejo（`deploy/forgejo/`），平台用管理员令牌建账号、建仓库、提交文件。
- 做题界面：Monaco 编辑器本地打包；独立的 `ide.css` 深色 IDE 主题，不用平台的玻璃组件。
