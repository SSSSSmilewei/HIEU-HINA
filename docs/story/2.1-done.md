# Story 2.1 — Forgejo 账号与仓库打通

## 主要目标
每个学员有 Forgejo 账号和仓库，每次提交自动 commit。

## 验收标准
- [x] 平台账号首次需要时自动在 Forgejo 建同名账号（管理员令牌，环境变量 `FORGEJO_URL`、`FORGEJO_TOKEN`）
- [x] 第一次开始一门课自动建仓库 `<用户>/<课程>`（私有），首次提交为官方起始代码
- [x] 每次判题提交：把学员文件 commit 到仓库对应目录，提交说明如「lab01 q3：提交，结果 AC」
- [x] 刷题 AC 后写入 `<用户>/oj-practice` 仓库，按题号归档
- [x] Forgejo 不可用时判题照常，仓库写入进入重试队列

## 功能要点
- 用 Forgejo 的多文件提交接口一次提交
- 提交作者用学员身份显示

## 单元测试用例设计
- 仓库路径、提交说明的生成
- 重试队列：失败后指数退避

## 行为测试用例设计
- 本地起 Forgejo：提交两次后仓库有两个 commit，diff 正确
