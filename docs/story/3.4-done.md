# Story 3.4 — 特殊题型：预测输出、环境图、Scheme、SQL、写测试、改错

## 主要目标
官方出现过的非函数题型都能做、能判。

## 验收标准
- [x] 预测输出（WWPD / ok 解锁）：逐行填写 Python 会显示什么，按官方加密答案比对（故事 3.1 做完；Scheme 的 wwsd-* 同样支持，lab10）
- [x] 环境图：逐帧填函数名、父帧、绑定、返回值；判题服务在沙箱里用 sys.settrace 实际运行程序（judge/harness/env_trace.py），逐帧比对，只提示哪里不对、不给答案。题目从讲义页的 PythonTutor 嵌入里提取（disc01 两道、disc02 一道），算出的帧和官方答案核对过；浏览器里填错、填对各试过一次
- [x] Scheme：编辑器支持 Scheme，判题用官方解释器（作业包里的 61A Code 解释器 editor/，在沙箱里逐条求值；过程按 ok 用的官方解释器的写法显示）。lab08、lab10、hw07–09 用官方解答逐题 AC
- [x] SQL：显示表结构，查询结果比对（和 ok 一样交给作业包里的 sqlite_shell.py，整段输出比对，ordered 为假时不计顺序；数据文件在编辑器里只读可看，超过 256 KB 的只给开头 200 行）。lab11、hw10 用官方解答逐题 AC
- [x] 写测试 / 改错：CS61A 2026 春季没有这两种题（「调试小测验」是选择题，按预测输出题做）。题型名保留在格式里，以后别的课用到再做判题

- 环境图的真实执行数据由判题服务在沙箱里跑出（记录每一步的帧）
