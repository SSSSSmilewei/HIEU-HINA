# Story 2.2 — 平台内的仓库页

## 主要目标
在平台里看自己的仓库：文件树、历史、每次改动，并能拿走。

## 验收标准
- [ ] `/repos` 列出我的所有仓库，`/repos/:name` 文件树 + 文件内容（IDE 风格高亮）+ 提交历史 + 单次 diff
- [ ] 自动生成并更新每个仓库的 README（学了什么、过了哪些题、做了哪些项目）
- [ ] 显示 clone 地址，一键镜像到 GitHub 的说明
- [ ] 仓库可见性开关（默认私有）

## 功能要点
- 数据从 Forgejo 接口读，平台不另存

## 单元测试用例设计
- README 生成内容

## 行为测试用例设计
- 打开仓库页，点一次提交看到 diff
