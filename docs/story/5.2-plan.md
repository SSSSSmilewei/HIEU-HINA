# Story 5.2 — 综合排行

## 主要目标
把作业、项目、刷题按权重综合排名。

## 验收标准
- [ ] 总分 = 作业分 × w1 + 项目分 × w2 + 刷题分 × w3，默认 0.3 / 0.4 / 0.3，管理者可调
- [ ] 作业分：完成的题数 × （0.8 + 0.2 × AI 质量分）
- [ ] 项目分：每个项目按完成的关数比例 × 项目权重
- [ ] 刷题分：简单 1、中等 2、困难 4，同难度每周超过 20 题后递减
- [ ] 周榜、学期榜、总榜；每人可看自己的得分明细

## 功能要点
- 每天或每次 AC 后增量更新

## 单元测试用例设计
- 计分公式各项

## 行为测试用例设计
- 造三位同学的数据，排行顺序符合公式
