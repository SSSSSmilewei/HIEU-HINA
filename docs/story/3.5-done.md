# Story 3.5 — 考核

## 主要目标
官方考试接成限时测验；作为结课验收。

## 验收标准
- [x] 3 场考试改编成限时测验：开始后计时，到时自动交卷。格式 hiana-exam@1、接口 /api/exams/*、页面 /courses/:slug/exam/:id、迁移 v19。改编 2025 秋季期中 1（34 分）、期中 2（46 分）、期末（75 分，结课测验）；原卷里是图片的环境图题和 0 分的 A+ 题不收。标准答案代回官方框架跑过官方 doctest（期中 2 共 32 个、期末和期中 1 共 48 个，全部通过）；浏览器里完整做过期中 1 和期末
- [x] 题型：单选、多选、填空（预测输出也用填空）、写代码（判题服务按只读的 ok 测试判，按通过比例给分）
- [x] 成绩只本人和管理员可见；结课测验达到及格线（默认 70%）在测验页显示协会课程完成凭证，可打印或存成 PDF

## 功能要点
- 考试中禁用 AI（已做：有进行中的测验时 /api/oj/ai/* 返回 403）和提示
- 标准答案只打进 Worker（src/worker/examData.ts），网页拿到的试卷不带答案；交卷后才给完整试卷

## 单元测试用例设计
- 计时与自动交卷；评分汇总

## 行为测试用例设计
- 完整做一场测验并看到成绩
