# Story 3.7 — 深海游戏地图

## 主要目标
CS61A 的入口是一张游戏地图：每周一段航线，每份作业 / 讲座一个点，过关点亮。

## 验收标准
- [x] 深海风格地图，节点按周排列，显示已完成 / 进行中 / 可做 / 建议先完成前面的（不锁内容）。地址改成 `/courses/:slug/sea`，因为 `/courses/:slug/map` 已经是「闯关」地图；课程页有入口（有作业台的课才显示）
- [x] 经验值（讲义 10、每题 5、项目每题 10、整份作业 +20、测验及格 100）、徽章（第一次通过、完成四个项目、期中通过、浮出水面、半程）。连续学习的徽章需要按天统计，留到综合排行（5.2）一起做
- [x] 点节点进入讲义、作业台（取完成得最多的版本）或测验

## 功能要点
- 地图数据由课程包、作业包、通过记录、测验成绩算出（src/client/seaMap.ts，纯函数，tests/sea-map.test.ts）
