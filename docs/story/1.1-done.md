# Story 1.1 — 题目与作业包格式

## 主要目标
定义 `hiana-problem@1`（一道题）和 `hiana-assignment@1`（一份作业），平台、判题服务、适配器都按它读写。

## 验收标准
- [x] `src/shared/problem.ts` 用 zod 定义两种格式并导出类型
- [x] 题型覆盖：function、io、project、wwpd、envdiagram、scheme、sql、writetests、fixbug
- [x] 每题包含：题面（中/英）、语言、起始文件（可改/只读）、要改的位置、公开测试、隐藏测试（可选）、限制、知识点、三级提示、讲解
- [x] 作业包包含：课程、学期、出处、许可、对应课程条目、仓库目录、题目列表
- [x] `npx tsx scripts/schema.ts` 生成 `content/schema/` 下的 JSON Schema，测试检查同步
- [x] 不含参考解字段（PRD 决定 9）

## 功能要点
- 题目源文件放 `content/oj/`：`assignments/<course>/<id>/assignment.json` + 起始代码目录；刷题题目放 `content/oj/problems/<id>/`
- 构建时校验所有题目，不合法就构建失败
- 限制默认值：时间 2 秒、内存 256 MB，可按题覆盖

## 单元测试用例设计
- 合法的作业包通过校验
- 缺题面、题型未知、可改文件不存在于起始文件中 → 校验报错并指出路径
- JSON Schema 与 zod 定义一致（复用现有 schema 测试方式）

## 行为测试用例设计
- 构建时放一份故意写错的题目，`npm run build` 失败并给出可读的错误
