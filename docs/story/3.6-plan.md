# Story 3.6 — 学习间：视频换源与讲义并排

## 主要目标
看课的地方：视频可换源，和讲义、幻灯片并排。

## 验收标准
- [ ] 每一讲多个视频源：B 站（AI 字幕）、其他翻译版本、YouTube 原片，一键切换，记住选择
- [ ] 管理者能给一讲添加视频源
- [ ] 视频和讲义并排；幻灯片可翻页
- [ ] 理解检查（少量选择 / 填空）嵌在讲义里，不是刷题
- [ ] 钉子、AI 问答在学习间可用（AI 知道当前讲、当前段落）

## 功能要点
- 课程包加视频源字段（只加不改）

## 单元测试用例设计
- 换源选择的存取

## 行为测试用例设计
- 打开第 1 讲，在两个源之间切换
