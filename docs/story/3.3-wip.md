# Story 3.3 — 四个项目

## 主要目标
Hog、Cats、Ants、Scheme 解释器按问题分关，多文件，能在站内玩图形界面。

## 验收标准
- [x] 每个项目一份作业包，按官方 Problem 分题，题与题代码累积（同一份作业共用一份草稿）：Hog 17 道、Cats 10 道、Ants 30 道、Scheme 20 道。官方测试里「先解锁的理解题（concept）」拆成前面单独的一道选择题。用一份公开的 2025 秋季学员解答逐题提交，除 Ants 附加题 EC1（两个学期的附加题规则不同）外全部 AC
- [x] 多文件：ok 配置里的源文件都可改（主文件排第一），其余只读；Scheme 项目用学员自己写的解释器跑 scm> 测试（和 ok 一样）
- [ ] 图形界面：在浏览器里用学员自己的代码运行游戏（只展示，不判题）。Hog 已做：作业台下方「试玩」标签，Pyodide 跑学员的 hog.py，和官方 hog_gui.py 一样每步重放来算分数，可以两人轮流或和自己的策略对战（2026-11-26）。还差 Cats（打字测速）、Ants（棋盘）、Scheme（交互式解释器）
- [x] 项目完成后仓库里是完整的项目代码（第一次提交时放入官方起始代码，之后每次提交更新学员改的文件；超过 256 KB 的数据文件不进仓库）

## 功能要点
- 只用于图形界面和本地服务器的文件（libs/、static/、gui_files/、images/ 等）不进作业包；图形界面另做
- 判题补的几种 ok 写法：期望输出是整段 Traceback；没有期望输出的用例（不报错就算过）；# choice: 注释；DEBUG: 调试行不算输出；用例很多时结果只留失败用例的详情
- 官方 GUI 依赖本地服务器的部分，改为浏览器端运行（Pyodide）
