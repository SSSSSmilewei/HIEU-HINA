# Story 2.2 — 平台内的仓库页

## 主要目标
在平台里看自己的仓库：文件树、历史、每次改动，并能拿走。

## 验收标准
- [x] `/repos` 列出我的所有仓库，`/repos/:name` 文件树 + 文件内容（IDE 风格高亮）+ 提交历史 + 单次 diff
- [x] 自动生成并更新每个仓库的 README（学了什么、过了哪些题、做了哪些项目）
- [x] 显示 clone 地址，一键镜像到 GitHub 的说明
- [x] 仓库可见性开关（默认私有）

## 功能要点
- 数据从 Forgejo 接口读，平台不另存

## 单元测试用例设计
- README 生成内容

## 行为测试用例设计
- 打开仓库页，点一次提交看到 diff

## 完成记录（2026-11-28）
- 接口 `src/worker/api/repos.ts`，都在 `/api/git/` 下（`/api/repos/:slug` 已被闯关的旧接口占用，旧路径不变）：
  - `GET /api/git/repos` 列表；`GET /api/git/repos/:name` 文件树；`GET /api/git/repos/:name/file?path=` 文件内容（二进制和超过 512 KB 的只给大小）；
  - `GET /api/git/repos/:name/commits?page=` 提交历史（每页 30 条）；`GET /api/git/repos/:name/commits/:sha` 一次提交和改动对比（最多 1 MB）；
  - `POST /api/git/repos/:name/visibility` 改公开或私有；`POST /api/git/password` 设置 Git 密码。
  - 仓库主人固定是当前账号对应的 Forgejo 用户，请求里不带主人，看不到别人的仓库。管理员查看学员仓库暂未做。
- 页面 `src/client/pages/Repos.tsx`，样式在 `src/client/ide/ide.css` 末尾（`.repo-*`），和做题界面一样是全屏 IDE 风格：
  - 文件树可折叠、可拖宽；代码用只读 Monaco 高亮；Markdown 默认显示排好版的预览，能切换源码；README 里的相对链接在文件树里打开。
  - 提交历史分页加载；点一次提交看到改了哪些文件和逐行改动（新旧行号、增删着色）。
  - 「克隆」面板给出 HTTPS 地址和命令；`/repos` 页有设置 Git 密码、克隆、推送、镜像到 GitHub 的说明。
  - 入口：「我的」页的「我的仓库」卡片。
- 为了让 clone 地址真的能用，加了「设置 Git 密码」：平台用管理员令牌改学员 Forgejo 账号的密码，只用于 clone 和 push，和平台登录密码互不影响。学员账号原来的密码是随机的，学员不知道。
- README 生成在 `src/worker/forgejo.ts` 的 `courseReadme`，每次同步提交后重新生成，内容没变就不提交。
- 测试 `tests/repos.test.ts`（7 个）、`tests/forgejo.test.ts`。
- 本机 Forgejo（127.0.0.1:3310）实测：列表、文件树、README 预览、提交历史、改动对比、公开 / 私有切换都正常；设置 Git 密码后 `git clone`、`git push` 成功，推送的提交在网页的提交历史里出现。
- 截图检查过深色、浅色、手机宽度（390px）。
