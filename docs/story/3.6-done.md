# Story 3.6 — 学习间：视频换源与讲义并排

## 主要目标
看课的地方：视频可换源，和讲义、幻灯片并排。

## 验收标准
- [x] 每一讲多个视频源：B 站（AI 字幕）、其他翻译版本、YouTube 原片，一键切换，记住选择（讲义页嵌入播放器，src/client/components/VideoPlayer.tsx；选过的网站记在浏览器里，下一讲自动选同一个网站）
- [x] 管理者能给一讲添加视频源（播放器下方「添加视频源」，接口 /api/admin/videos，迁移 v20）
- [x] 视频和讲义并排（宽屏「和讲义并排看」，视频固定在右侧；窄屏放在讲义上方）；幻灯片翻页：CS61A 的幻灯片是外链 PDF，在「链接」里打开，暂不内嵌
- [x] 理解检查（少量选择 / 填空）嵌在讲义里，不是刷题（讲义页原有的练手题；有作业台的 lab / hw 才隐藏）
- [x] 钉子、AI 问答在学习间可用（蓝色钉子钉在段落上，「请 AI 回答」带着段落内容）

## 功能要点
- 课程包加视频源字段（只加不改）
