# 调研：Codédex（codedex.io）

> 2026-11-22 写。负责人一直觉得 Codédex 很好，让 AI 认真研究，第二天一起讨论。
> 方法：Codédex 的网页靠浏览器脚本生成，直接抓只能拿到标题，所以这次是下载它公开的页面数据和前端脚本、它在 GitHub 上公开的仓库，再加几篇第三方评测。下面标「看到」的是从它自己的数据里直接读到的；标「评测说」的来自第三方，没有核实。
> 讨论的来龙去脉见 `docs/灵感备忘录.md` 第八节。

## 一、它是什么

- 面向零基础的编程学习网站，定位「给青少年和成年人的新的学编程方式」。创始人 Sonny Li 以前在 Codecademy 做了五年课程，2022 年辞职单干，团队在纽约。
- 包装成一场冒险：「穿越 Python、HTML、CSS、JavaScript 的奇幻大陆，赚经验值（XP）解锁新地区，按自己的节奏集齐徽章」（看到，首页简介）。
- 规模：Python 入门课显示有约 125 万人报名（看到）。课程目录里有二十多门课：Python、HTML、CSS、JavaScript、命令行、Git 与 GitHub、React、SQL、C++、Java、Lua、NumPy、pandas、Matplotlib、机器学习、数据结构与算法、生成式 AI、Phaser（网页游戏）、UI/UX 等（看到，网站地图）。
- 课程名起得像游戏：Python 叫「The Legend of Python」，HTML、CSS、JavaScript 三门叫「The Origins I / II / III」（看到）。

## 二、一门课的结构（以 C++、Python 为例，看到）

```
课程
├─ 第 1 章 Hello World（徽章：地球）      练习 ×5，每题 10–15 XP
│    └─ 章末解锁：Bonus Article（加餐文章）、Challenge Pack（支线练习包）
├─ 第 2 章 Variables                     练习 ×7
├─ 第 3 章 Conditionals                  练习 ×6
├─ 第 4 章 Loops                         练习 ×5，附速查表 PDF
├─ Checkpoint Project（检查点项目）      三选一，比如密码检查器 / 计算器 / 文字冒险游戏
├─ 第 5 章 …
├─ Final Project（毕业项目）             「用学到的东西做一个完整的项目」
└─ Course Certificate（课程证书）
```

- **章**：每章有名字、一句话简介、一枚徽章，章与章之间播一段**过场动画**（带音频）。
- **练习**：每章 5–7 道，每道几分钟，经验值 10–20。章与章之间的练习**互相独立**，每道是一个单独的小程序（比如「打印名字首字母的大字」「BMI 计算器」「99 瓶啤酒」）。
- **检查点项目**：课程中途，三个题目选一个，写完提交代码。
- **毕业项目**：课程最后，自由发挥，提交链接。
- **证书**：申请证书时，由导师审核检查点项目和毕业项目（看到，原话是「申请课程证书时，你的项目会由导师审核」）。

## 三、一道练习长什么样（以 Python 第 4 题 Initials 为例，看到）

一道练习的数据有这些字段：

| 字段 | 内容 |
|---|---|
| 标题和一句话说明 | 「04. Initials：用大字打印你的名字首字母」 |
| 讲解 | 一小段正文：注释是什么、怎么写，配两个代码例子 |
| 任务（Instructions） | 「写一个 initials.py，先用注释写一个关于自己的冷知识，再用大字打印首字母」，配示例输出 |
| 提示（Hint） | 折叠起来：「大概要 7 个 print()，一行一个」 |
| 文件名 | `initials.py`，编辑器里预先建好 |
| 经验值 | 15 |
| 讲解视频 | 每道题一段视频 |
| 参考答案 | 放在它的 GitHub 公开仓库里，MIT 许可，欢迎大家提交自己的解法 |
| **评判标准（evalGuidelines）** | 写给 AI 看的一句话：「只要有一个能运行的 print() 就算通过」 |

### 怎么判对错（看到，前端脚本里的流程）

1. 先用**正则表达式**检查代码里有没有该有的东西，比如有没有 `print(`。不符合就给出这条规则对应的提示。
2. 通过以后，交给 **AI 按评判标准判**。AI 说不对时，会给出 AI 反馈；页面上还有一个「我的答案其实是对的」按钮，学生可以申诉。
3. 判对了：放礼花，加经验值，有时发新徽章。

也就是说，**它不跑测试用例**，靠正则加 AI。好处是出题快、能判开放式的题（「画一个你喜欢的图案」），坏处是不严格：同样的代码可能这次过、下次不过，也判不了「算法对不对」。

### 代码在哪里运行（看到）

- 编辑器是 Monaco（VS Code 用的那个编辑器），支持多个文件。
- 网页类课程（HTML、CSS、JavaScript、p5.js、Phaser）在浏览器里直接运行；数据科学类课程里有基于 Pyodide 的 Python 控制台。
- 其他语言（C++、Java）具体怎么运行，脚本里没看出来，可能在它的服务器上。

## 四、让人想继续学的设计

| 设计 | 说明 |
|---|---|
| 经验值和等级 | 每题有经验值，累计到个人资料里，有段位徽章 |
| 徽章 | 每章一枚，每门课一枚金徽章 |
| 过场动画 | 开始一门课、学完一章时播，有音乐 |
| 连续天数 | 记录每天学习的连续天数 |
| 像素风画面 | 像素字体、复古游戏机风格的按钮，课程横幅是像素画 |
| 文案 | 很口语、很热情。学完 JavaScript 课的提示是「你真的做到了！从第一行 console.log() 到拿下前端三件套……去庆祝吧，你值得」 |
| 加餐和支线 | 每章学完解锁一篇加餐文章和一个练习包（Challenge Pack），可以跳过 |
| 速查表 | 每门课有一两页 PDF |

## 五、课程以外

| 板块 | 内容 |
|---|---|
| 项目教程（Projects） | 64 篇以上，由工程师、学生写，比如「用 Python 写猜词游戏」「用 Arduino 做口袋迪斯科」「做一个 Minecraft 模组」。每篇是一步一步的长教程，标注难度、前置知识、阅读时间，最后附可以继续学的加餐文章 |
| 练习（Challenges） | 每日挑战、按主题的练习包 |
| Builds | 网页里的在线编辑器，自己做项目、分享代码；可以用 AI 起个头（比如「做一个习惯打卡器」） |
| 社区 | Discord、排行榜、项目展示、每月挑战（做完在直播里展示）、#30NitesOfCode（30 天打卡）、线上答疑、游戏夜 |
| AI 助教 Lumi | 在练习页里问问题；免费用户有次数限制 |

## 六、收费（评测说，和它的价目表脚本对得上）

- 免费（Explorer）：每门课的前几章、项目教程、练习包、Discord、有限次数的 AI。
- 付费会员（Club）：全部课程、导师随时答疑、项目审核、**证书**、不限次数的 AI、简历和面试辅导。价格各处说法不一，约每月 8–13 美元，部分国家有地区定价。
- 评测里的主要抱怨：大部分内容要付费；水平高一些以后会觉得太浅。

## 七、对我们的启发

### 1. 值得学的

- **关卡的颗粒度**：一题几分钟，讲解、任务、提示、编辑器、判题都在同一页上。我们现在的练手题已经有判题，但讲解和题目分在两处，讲义是一整篇长文。
- **一道题的数据格式**：讲解、任务、提示、文件名、经验值、视频、评判标准，字段很清楚。我们的课程包格式（`hiana-course@1`）可以照这个思路加一个「关卡」条目类型。
- **章的节奏**：练习 → 检查点项目 → 练习 → 毕业项目 → 证书。章末有徽章和过场，给人「过了一关」的感觉。
- **加餐和支线可以跳过**：主线短，想多练的同学有地方去。
- **项目教程**：把一个完整的项目拆成一步一步的长教程，和我们想做的「项目是主线」最接近。
- **社区活动**：每月挑战、展示会、30 天打卡，成本低，对协会尤其合适（我们有晚自习，可以线下办）。

### 2. 它没做到、正好是我们要做的

- **练习之间不连贯**：每道题是一个单独的小程序，做完第 30 题，手里是 30 个互不相关的文件，不是一个项目。这正是负责人说的「做了很多题，最后不知道在干什么」。我们想做的是：**关卡就是项目的步骤，全部通关以后，代码合起来就是官方项目的仓库。**
- **内容浅**：它是自己编的入门课，学到能写小程序为止。我们的主线是 CS50x、CS61A 这些名校课程，深度完全不同。
- **判题靠 AI**：结果不稳定，判不了算法对错。我们用官方测试改编的测试用例来判，AI 只写评语、给提示，结果可信，也能交到官方拿证书。
- **证书是它自己发的**：我们可以引导同学去拿官方的证书（CS50x），含金量更高。
- **要付费**：我们对协会成员免费。

### 3. 不能照搬的

- **它的画面和名字**：像素画、角色、过场、课程名都是它的作品，不能照着做一个「换皮的 Codédex」。可以学机制（经验值、徽章、章末过场、支线），画面要有我们自己的风格。我们本来就有液态玻璃皮肤和深海蓝的协会形象，可以往「深海探险」这个方向想（开场动画已经有这个基调）。
- **它的课程内容**：讲解和题目是它写的，不能搬。它 GitHub 上的参考答案是 MIT 许可，可以参考，但用处不大，因为我们的主线是名校课程。
- **口语化的文案**：负责人定过界面文案要正式、完整，这一点和 Codédex 不同。关卡里的鼓励语可以温和一些，但不写网络口语。这一点要和负责人确认。

## 八、明天想和负责人确认的

1. Codédex 里最喜欢的是哪几样：画面、过场和徽章、一题几分钟的节奏、项目教程，还是社区活动？
2. 「关卡 = 项目的步骤」和 Codédex「练习互相独立」的差别，是不是负责人想要的方向？
3. 画面风格：要不要做游戏感很强的画面（地图、角色、过场）？还是在现在的液态玻璃风格里加经验值、徽章就够了？前者好看，但美术工作量大，要有人画。
4. 判题：坚持用测试用例判，AI 只做提示和评语，这样可以吗？
5. 文案：关卡里可不可以比现在的界面活泼一点？
