# 海纳协会 OJ · VSCode 插件

在自己电脑上用 VSCode 写海纳协会学习平台的作业。网页里的作业台和本地是同一个 Git 仓库：在这里提交的代码，网页上的仓库页和提交记录里都能看到。

## 第一次使用

1. 点 VSCode 左侧竖栏的 **HIANA**，再点 **登录**。浏览器会打开平台的确认页，核对确认码后点「允许」。
2. 回到 VSCode，在 **我的仓库** 里点要下载的仓库。仓库默认下载到「文档/HIANA」，下载完自动打开。Git 用户名和密码由插件自动处理，不用另外设置。

## 写代码

- **在服务器上运行**（编辑器右上角 ▷）：把当前文件和同一个文件夹里的同类文件（Python 模块、C/C++ 头文件）发到平台的服务器上运行，本机不用安装 Python、C、C++ 或 Java。程序需要输入时，在同一个文件夹里放一个和代码同名的 `.in` 文件（例如 `main.in`），或者 `input.txt`。每次最多运行 5 秒、使用 256 MB 内存，每分钟最多 10 次；不能单步调试，也不能边运行边从键盘输入。
- **运行公开测试**：只跑公开用例，不留提交记录。
- **提交到 OJ**：先把改动提交并推送到你的仓库，再交给平台判题（公开用例和隐藏用例都跑），结果显示在「HIANA OJ」输出面板。

后两个按钮只在作业文件里出现。一个文件里有好几道题时，会让你选这次运行或提交哪一题，并记住上次的选择。左侧 HIANA 栏的 **当前作业** 列出正在写的这份作业的每道题是否已经通过，点题目打开对应的文件。

其他命令（`Ctrl+Shift+P` 输入 HIANA）：查看提交记录、在平台上打开这道题、平台地址、使用令牌登录、退出登录。

## 说明

- 预测输出、环境图这两类题要逐空作答，只能在平台的作业台里做。
- 插件登录以后只能查看仓库、运行和提交代码、查看提交记录，不能改密码或做别的操作。不再使用的电脑，请在平台「我的仓库」页撤销它的令牌；改过平台密码以后，所有令牌自动失效。
- 插件用的 Git 密码保存在插件自己的目录里，只有你的系统账号能读，只用于平台上的仓库。
- 设置里的 `hiana.server` 是平台地址，`hiana.repoFolder` 是仓库下载位置。
