# 海纳协会 OJ · VSCode 插件

在自己电脑上用 VSCode 写海纳协会学习平台的作业。网页里的作业台和本地是同一个 Git 仓库：在这里提交的代码，网页上的仓库页和提交记录里都能看到。

## 第一次使用

1. 在平台打开「我的 → 我的仓库」：
   - 设置 **Git 密码**（克隆和推送时用，用户名就是页面上显示的 Git 用户名）；
   - 在「VSCode 插件」一节**签发令牌**，复制下来（令牌只显示一次）。
2. 在 VSCode 里按 `Ctrl+Shift+P`，运行 **HIANA：登录**，平台地址直接回车，再粘贴令牌。
3. 运行 **HIANA：克隆我的课程仓库**，选择课程，选一个保存位置。VSCode 询问账号密码时，填第 1 步里的 Git 用户名和 Git 密码。

## 写作业

打开作业文件（比如 `lab/lab01/lab01.py`），编辑器右上角有两个按钮：

- **运行公开测试**：只跑公开用例，不留提交记录。
- **提交到 OJ**：先把改动提交并推送到你的仓库，再交给平台判题（公开用例和隐藏用例都跑），结果显示在「HIANA OJ」输出面板。

一个文件里有好几道题时，会让你选这次运行或提交哪一题，并记住上次的选择。

其他命令（`Ctrl+Shift+P` 输入 HIANA）：查看提交记录、在平台上打开这道题、退出登录。点状态栏左下角的「HIANA」也能打开操作菜单。

## 说明

- 预测输出、环境图这两类题要逐空作答，只能在平台的作业台里做。
- 令牌只能用来运行、提交、查看提交记录和仓库，不能改密码或做别的操作。不用了请在平台上撤销；改过平台密码以后，旧令牌会自动失效。
