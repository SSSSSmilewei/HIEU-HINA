# 开始之前：这门课怎么学

MIT 18.06SC 的全称是 Linear Algebra（线性代数），由 Gilbert Strang 教授讲授。站内的版本是 MIT 开放式课程（OpenCourseWare）2011 年秋季为自学者整理的「Scholar」版，讲座录像来自 2005 年春季的课堂。

## 每一讲里有什么

| 内容 | 说明 |
|---|---|
| 讲座视频 | 哔哩哔哩中英双语字幕版（每讲一集）和官方 YouTube 版。 |
| 讲座摘要 | 官方讲座摘要（lecture summary）的中文翻译，概括这一讲的定义、定理和例子。 |
| 习题讲解视频 | 助教讲解一道典型习题的短视频，部分讲有普通话版本。 |
| 习题与解答 | 官方习题和解答的中文翻译，以及据此改编的练手题，可以在站内直接作答。 |
| 阅读 | Strang 教授的教材 Introduction to Linear Algebra（第 4 或第 5 版）对应的章节。 |

每个单元结束时有一次复习课和一次考试，最后是期末复习和期末考试，都附有试题和解答。

## 建议的学习顺序

每一讲：看讲座视频 → 读讲座摘要 → 看习题讲解视频 → 自己做习题，再对照解答 → 做练手题。

全课程 35 讲，按每周 3 讲的进度大约需要 12 周。线性代数在后续的机器学习、计算机图形学、信号处理等课程里随处可见，建议把习题都动手做一遍。

## 教材

教材 Introduction to Linear Algebra 需要另外购买，中文版书名是《线性代数导论》。没有教材也能学完这门课：讲座视频和讲座摘要已经覆盖了全部内容。

## 公式显示

讲义里的数学公式在网页上会正常显示。手机 App 暂时还不能显示公式，看到的是公式的原文（LaTeX 写法），建议在网页上阅读这门课。
