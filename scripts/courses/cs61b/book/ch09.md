## 9.1 子类型多态与函数传递

**运算符重载**

假设我们定义一个 Dog 类：

```python
class Dog:
   def __init__(self, name, size):
       self.name = name
       self.size = size
  
   def __gt__(self, other):
       return self.size > other.size
```

下面的 Python 代码可以用来找出一个 Dog 列表里最大的 Dog。

```python
def get_the_max(x):
   max_value = x[0]
   for item in x:
       if item > max_value:
           max_value = item
   return max_value

max_dog = get_the_max(doglist)
```

Python 里的 get\_the\_max 函数是通用的，能用于任何类型。它利用「运算符重载」（operator overloading）实现了这种通用性。

更一般地说，这种处理任何类型的能力有时叫作「多态」（polymorphism），我借用维基百科的定义：「在编程中为不同的底层形式提供相同编程接口的能力」\[[维基百科](https://en.wikipedia.org/wiki/Polymorphism)]。

在这里，> 运算符让 Python 能比较任何东西（即「任何底层形式」）。而 > 的定义由 `__gt__` 给出。

## 9.2 Comparable 与 Comparator

### Comparable

作为引入的例子，考虑下面的 Java 代码，我们想在一个狗的列表里找出最大的狗。

```java
List<Dog> dogs = new ArrayList<>();
dogs.add(new Dog("Grigometh", 200));
dogs.add(new Dog("Pelusa", 5));
dogs.add(new Dog("Clifford", 9000));
Dog maxDog = Collections.max(dogs);
```

这段代码差不多能用，但有一个问题：Java 不知道怎样比较狗。这会产生一条相当难懂的错误信息：「no instance(s) of type variable(s) T exist so that Dog conforms to Comparable\<? super T>」。

Python 里我们定义了 `__gt__` 方法来支持比较；和 Python 不同，Java 没有运算符重载。我们必须利用实现继承（这里实际是实现一个接口）。具体地说，我们要实现下面给出的 `Comparable` 接口：

```java
public interface Comparable<T> {
    int compareTo(T o);
}
```

正如课上前面看到的，`compareTo` 方法在第一个参数小于、等于、大于第二个参数时，分别返回负整数、零、正整数。如果好奇，也可以看看 Comparator.java 的源代码，见 [这个链接](https://github.com/openjdk/jdk/blob/ab66c82ce9fdb5ee3fd7690f42b8ad4d78bf5e40/src/java.base/share/classes/java/lang/Comparable.java#L105)。

实现了 `Comparable` 接口之后，得到下面的代码：

```java
public class Dog implements Comparable<Dog> {
   ...
   @Override
   public int compareTo(Dog uddaDog) {
       if (size > uddaDog.size) {
           return 1;
       }
       if (size < uddaDog.size) {
           return -1;
       }
       return 0;
   }
}
```

实现了这个接口之后，`Collections.max(dogs)` 就能用了。

上面写的代码虽然能用，但有点笨拙。另一种写法如下：

```java
public class Dog implements Comparable<Dog> {
   ...
   @Override
   public int compareTo(Dog uddaDog) {
       return this.size - uddaDog.size;
   }
}
```

这里直接把两个大小相减，省了几行代码。返回两个数之差，是 Java 里实现 `compareTo` 方法的一种常见写法。

我们刚刚用到的这种**多态**，有时叫作**子类型多态**（subtype polymorphism）。

这里的思想是：一个父类型（`Comparable`）规定一种能力（在这里是比较）。然后一个子类型（`Dog`）重写父类型的抽象方法。在运行时，Java 根据调用方法的那个对象的类型来决定做什么。

### Comparator

「自然顺序」（Natural Order）这个词有时用来指 `Comparable` 的 `compareTo` 方法所隐含的顺序。我们的 compareTo 方法把大小看作狗的自然顺序。

有时我们想考虑别的顺序。例如，我们可能想按名字给狗排序。

在 Python 里，我们用函数传递来达到这个目的。例如，在下面的代码里，我们把 `name_len` 作为键函数传给 `get_the_max`。

```python
def get_the_max(x, key):
  max_value = x[0]
  for item in x:
    if key(item) > key(max_value):
      max_value = item
  return max_value

def name_len(dog):
   return len(dog.name)

max_dog=get_the_max(doglist, name_len)
```

相比之下，Java 代码通常不用函数传递来处理其他顺序，而是再次依靠**子类型多态**。

具体地说，我们可以实现下面给出的 `Comparator` 接口：

```java
public interface Comparator<T> {
    int compare(T o1, T o2);
}
```

下面是一个按名字比较狗的 `Comparator` 的例子：

```java
public static class NameComparator implements Comparator<Dog> {
   @Override
   public int compare(Dog a, Dog b) {
       return a.name.compareTo(b.name);
   }
}
```

要检验你对这些思想的理解，考虑这道题：下面代码的输出是什么？

```java
Dog a = new Dog("Frank", 1);
Dog b = new Dog("Zeke", 1);
Comparator<Dog> nc = new Dog.NameComparator();
System.out.println(nc.compare(a, b));
```

是正数？负数？还是零？

### 使用 Comparator

下面的代码展示了怎样把一个 `Comparator` 传给 `Collections.max` 的例子。

```java
List<Dog> dogs = new ArrayList<>();
dogs.add(new Dog("Grigometh", 200));
dogs.add(new Dog("Pelusa", 5));
dogs.add(new Dog("Clifford", 9000));
Dog maxNameDog = Collections.max(dogs, new Dog.NameComparator());
```

这和在 Python 里把键函数传给 `get_the_max` 相似。

```python
def length_of_name(dog):
   return len(dog.name)

dogs = [Dog("Grigometh", 10),
        Dog("Pelusa", 5),
        Dog("Clifford", 9000)]
max_dog = get_the_max(dogs, length_of_name)
```

注意这里的区别。在 Java 里，我们把比较函数包装在一个 `Comparator` 对象里，即依靠子类型多态。

相比之下，在 Python 里，我们把比较函数传给 `get_the_max`，即依靠函数传递。

### 小改进

（在我看来）实例化 NameComparator 很别扭，也不美观。为了传一个比较函数而必须实例化一个类，这似乎很奇怪。

一个修正办法是加一个静态变量，引用一个预先实例化好的 NameComparator。我们在 Dog 类里这样做：

```java
public class Dog {
   ...
   public static final Comparator<Dog> NAME_COMPARATOR = new NameComparator();
}
```

这样就可以把 `Dog.NAME_COMPARATOR` 传给 `Collections.max`，而不必实例化一个新的 `NameComparator` 对象。写出来的代码是这样的：

```java
List<Dog> dogs = new ArrayList<>();
dogs.add(new Dog("Grigometh", 200));
dogs.add(new Dog("Pelusa", 5));
dogs.add(new Dog("Clifford", 9000));
Dog maxNameDog = Collections.max(dogs, Dog.NAME_COMPARATOR);
```

这真的更好吗？你来评判！

### 附加内容

也可以用 lambda 表达式实现一个 `Comparator`。如下所示：

```java
List<Dog> dogs = new ArrayList<>();
dogs.add(new Dog("Grigometh", 200));
dogs.add(new Dog("Pelusa", 5));
dogs.add(new Dog("Clifford", 9000));
Comparator<Dog> dc = (a, b) -> a.name.compareTo(b.name);
Dog maxNameDog = Collections.max(dogs, dc);
```

这样更简洁一些，但也更难读一些。这门课不要求你学 lambda 表达式。

## 9.3 编写一个 max 函数

我们已经看到 Java 为我们提供了好用的 `Collections.max` 函数。`Collections` 还包括其他方便的函数，比如 `min`、`sort` 和 `reverse`。

在本节里，我们会看到怎样自己编写这样的函数。

### 泛型函数（热身）

作为热身，假设我们想要一个从数组里随机挑一项的函数。下面是一些代码：

```java
public class RandomPicker {
    public static <T> T randomItem(T[] items) {
        Random random = new Random();
        int randomIndex = random.nextInt(x.length);
        return x[randomIndex];
    }
}
```

下面是一个使用这个函数的示例程序：

```java
public class RandomPickerDemo {
   public static void main(String[] args) {
       String[] x = {"hi", "little", "cat"};
       System.out.println(RandomPicker.pickRandom(x));
   }
}
```

（译注：原文这两段代码前后不一致：函数名写成了 `randomItem`，参数名是 `items`，函数体里用的却是 `x`；示例程序调用的是 `pickRandom`。下文统一用 `pickRandom(T[] x)`。）

接下来，我们试着让 `pickRandom` 函数能用于任何类型的数组。

#### 做法一：泛型

可以试着用泛型，如下面的代码所示：

```java
public class RandomPicker<T> {
   public static T pickRandom(T[] x) {
       Random random = new Random();
       int randomIndex = random.nextInt(x.length);
       return x[randomIndex];
   }
}
```

不过，这段代码这样写其实讲不通。`pickRandom` 函数是静态的，但我们得实例化一个 `RandomPicker` 对象才能指定泛型类型。也就是说，我们得这样写：

```java
String[] x = {"hi", "little", "cat"};
RandomPicker<String> stringPicker = new RandomPicker<>();
System.out.println(stringPicker.pickRandom(x));
```

但我们不能用实例去调用静态方法。

一个修正办法是把 `pickRandom` 函数改成非静态的，如下所示：

```java
public class RandomPicker<T> {
   public T pickRandom(T[] x) {
       Random random = new Random();
       int randomIndex = random.nextInt(x.length);
       return x[randomIndex];
   }
}
```

这样做，代码就能正常工作，但必须实例化一个挑选器对象，还是很别扭。

#### 做法二：泛型静态方法

正确而且更好的做法，是把静态方法本身写成泛型的。如下所示：

```java
public class RandomPicker {
   public static <T> T pickRandom(T[] x) {
       Random random = new Random();
       int randomIndex = random.nextInt(x.length);
       return x[randomIndex];
   }
}
```

这种语法让人困惑（后面还会更糟！）。可以这样读 `public static <T> T pickRandom(T[] x)`：「我在声明一个公有的静态函数，它作用于类型为 <T> 的对象，返回一个 T，名叫 pickRandom，接收一个 T 的数组作为输入。」

告诉 Java 我们的静态方法是泛型的之后，就可以不实例化 `RandomPicker` 对象而直接调用它，如下所示：

```java
public class RandomPickerDemo {
   public static void main(String[] args) {
       String[] x = {"hi", "little", "cat"};
       System.out.println(RandomPicker.pickRandom(x));
   }
}
```

注意，和泛型类不同，调用泛型静态方法时不需要指定泛型类型（即 `pickRandom` 后面没有 `<String>`）。类型会被自动推断出来。

一个小麻烦是，我们的 pickRandom 函数不能用于基本类型的数组，即不能用 `int[]`、`double[]`、`float[]`。

（译注：原文这里写的是「我们可以用」（we can use），按上下文应为「不能用」，译文已更正。）

```java
public class RandomPickerDemo {
   public static void main(String[] args) {
       int[] x = {1, 2, 3, 4, 5, 6, 7, 8};
       System.out.println(RandomPicker.pickRandom(x));
   }
}
```

这个问题没有办法绕过，事实上真实的 Java 库常常有多个函数，每种基本类型一个。例如，有 `Arrays.sort(int[])`、`Arrays.sort(double[])`、`Arrays.sort(float[])` 等等。也许有一天 Valhalla 项目会解决这个问题。

### 编写我们的 max 函数：类型上界

利用泛型静态函数的思想，可以这样写我们的 max 函数：

```java
public class Maximizer {
   public static <T> T max(T[] items) {
       T maxItem = items[0];
       for (int i = 0; i < items.length; i += 1) {
           int cmp = items[i].compareTo(maxItem);
           if (cmp > 0) {
               maxItem = items[i];
           }
       }
       return maxItem;
   }
}
```

还剩最后一个问题：Java 不知道 `T` 有 `compareTo` 方法。可以给泛型类型加一个**类型上界**（type bound）来解决，如下所示：

```java
public class Maximizer {
   public static <T extends Comparable<T>> T max(T[] items) {
       T maxItem = items[0];
       for (int i = 0; i < items.length; i += 1) {
           int cmp = items[i].compareTo(maxItem);
           if (cmp > 0) {
               maxItem = items[i];
           }
       }
       return maxItem;
   }
}
```

这告诉 Java，不论 `T` 是什么，它都必须实现 `Comparable<T>`。如果试着把一个元素没有实现 `Comparable<T>` 的数组传给 max，会得到一个编译期错误。

可以这样读 `public static <T extends Comparable<T>> T max(T[] items)`：「我在声明一个公有的静态函数，它作用于类型为 <T> 的对象，返回一个 T，名叫 max，接收一个 T 的数组作为输入。此外，T 必须实现 Comparable<T>。」

#### 附加：一个更好的类型上界

在真正工业级的 Java 代码里，这个方法的正确写法是：

```java
public class Maximizer {
   public static <T extends Comparable<? super T>> T max(T[] items) {
		...
   }
}
```

## 9.4 小结

### 自然顺序（Python 与 Java）

今天我们看到了**多态**和**函数传递**。

要用一种内在的顺序（也叫自然顺序）比较两个对象，Python 使用一种叫作**运算符重载**的多态形式。Java 则使用子类型多态。

```python
class Dog:
   def __init__(self, name, size):
       self.name = name
       self.size = size
  
   def __gt__(self, other):
       return self.size > other.size
```

```java
public class Dog implements Comparable<Dog> {
   ...
   @Override
   public int compareTo(Dog uddaDog) {
       return size - other.size;
   }
}
```

（译注：原文这段 Java 代码的参数名是 `uddaDog`，函数体里却写成 `other.size`，应为 `uddaDog.size`。）

注意：Python 是鸭子类型的：不必声明 > 是否可用。

### 其他顺序（Python 与 Java）

要用另一种顺序比较两个对象，Python 使用**函数传递**，即你提供一个键函数。相比之下，Java 和处理内在顺序时一样，使用子类型多态。我们把比较函数包装在一个 `Comparator` 对象里。

```python
class Dog:
   def __init__(self, name, size):
       self.name = name
       self.size = size

def name_len(dog):
   return len(dog.name)

max_dog=max(doglist, key=name_len)
```

```java
public static class NameComparator 
          implements Comparator<Dog> {
   @Override
   public int compare(Dog a, Dog b) {
       return a.name.compareTo(b.name);
   }
}
```
