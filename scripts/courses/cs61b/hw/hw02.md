## 语言结构

许多 Python 的基础知识在 Java 里都有对应的东西，例如循环和 if 语句。这一节把两边的语法直接放在一起对比。

### 变量声明

Python 写法：

```
i = 0
```

Java 写法：

```
int i = 0;
```

- 和 Python 一样，Java 的变量有*类型*（type）。在 Java 里声明变量时，必须显式写明它的类型；变量声明的类型永远不能改变。关于「静态类型」（static typing）的更多内容见第 1 讲。
- 语句末尾还必须加一个分号。

### 类型

| Python | Java | 说明 |
| --- | --- | --- |
| `bool` | `boolean` | Python 用 `True` 和 `False`；Java 用 `true` 和 `false`。 |
| `int` | `int` | Python 的 `int` 没有大小限制；Java 的 `int` 有（很大的）最大值和最小值。 |
| `float` | `double` | 表示小数。Java 的 `double` 同样有大小限制。 |
| `str` | `String` | Java 的 `String` 用双引号（`"`），可以是任意文本。 |
| 无对应 | `char` | Java 的 `char` 表示*单个*字符，用单引号（`'`）。 |

### 注释

Python 写法：

```
# This is a single line comment.
```

Java 写法：

```
// This is a single line comment.
```

（上面两行注释的意思都是「这是一个单行注释」。）Java 还有以 `/*` 开始、以 `*/` 结束的多行注释。

### `while` 循环

Python 写法：

```
i = 0
while i < 10:
    print(i)
    i += 1
```

Java 写法：

```
int i = 0;
while (i < 10) {
    System.out.println(i);
    i++;
}
```

- 条件两边的圆括号 `(` 和 `)` 是必需的。
- Java 里常用 `++` 代替 `+= 1`，不过 Josh 本人更喜欢 `+=`。
- 在 Java 里打印输出确实要用 `System.out.println`。抱歉。
- 我们不用缩进，而是用花括号 `{` 和 `}` 把属于 while 循环的代码括起来。Java 并不强制缩进，但缩进是好风格！

### `for` 循环

Python 写法：

```
for i in range(10):
    print(i)
```

Java 写法：

```
for (int i = 0; i < 10; i ++) {
    System.out.println(i);
}
```

在 Java 里，`for` 循环的语法是：

```
for (initialization; termination; increment) {
    // loop body
}
```

（三个占位词依次表示初始化、终止条件、递增；注释 `// loop body` 的意思是「循环体」。）它大致等价于下面的 while 循环：

Python 写法：

```
initialization
while termination:
    # loop body
    increment
```

Java 写法：

```
initialization
while (termination) {
    // loop body
    increment
}
```

while 循环和 for 循环都在终止条件为假时退出。上面对比里的 for 循环会一直运行「到」`i = 10` 为止。

下面是一个从 9 倒数到 0（包含 0）的 for 循环：

Python 写法：

```
for i in range(9, -1, -1):
  print(i)
```

Java 写法：

```
for (int i = 9; i >= 0; i --) {
  System.out.println(i);
}
```

- 注意 Java `for` 循环里「initialization」（初始化）、「termination」（终止条件）和「increment」（递增）三个部分在写法上的差别。
- 与 `++` 类似，常用 `--` 代替 `-= 1`。
- 上面对比里的 for 循环会一直运行「到」`i < 0` 为止。

### 条件语句

Python 写法：

```
if i % 3 == 0 and i % 5 == 0:
    print("FizzBuzz")
elif i % 3 == 0:
    print("Fizz")
elif i % 5 == 0:
    print("Buzz")
else:
    print(i)
```

Java 写法：

```
if (i % 3 == 0 && i % 5 == 0) {
    System.out.println("FizzBuzz");
} else if (i % 3 == 0) {
    System.out.println("Fizz");
} else if (i % 5 == 0) {
    System.out.println("Buzz");
} else {
    System.out.println(i);
}
```

布尔运算符如下：

| Python | Java |
| --- | --- |
| `and` | `&&` |
| `or` | `\|\|` |
| `not` | `!` |
| `==` | `==` |

- 注意 `elif` 和 `else if` 的区别。
- 注意：在 Java 里，`==` 判断的是同一性（identity），`.equals()` 判断的是相等（equality）。对基本类型（primitive type）来说两者一样，但对引用类型（reference type）可能不同。这份作业不需要知道它们的区别，我们以后会详细讲。

### 幂运算

Python 写法：

```
x = 2**10
```

Java 写法：

```
double x = Math.pow(2, 10);
```

- 注意 Java 里的 `^` 是「异或」（XOR）运算符，不是幂运算。也就是说，`2 ^ 10` 是合法的代码，但它返回 `8`，不是 `1024`。

### 函数

Python 写法：

```
def greet(name):
    return "Hello, " + name

# Elsewhere...
print(greet("Josh"))
```

Java 写法：

```
public static String greet(String name) {
    return "Hello, " + name;
}
// Elsewhere...
System.out.println(greet("Josh"));
```

（两处注释的意思都是「在别的地方……」。）

- 在 Java 里，函数要写明具体的返回类型，放在函数名之前；函数还必须写明参数的类型。
- 函数不返回任何值时，返回类型是 `void`。
- 目前我们所有函数的前面都有 `public static`。这些关键字的意思以后会讲。
- 调用函数的写法和 Python 一样。

### 字符串

Python 写法：

```
s = "hello"
s += " world"
s += str(5)
s_length = len(s)
substr = s[1:5]
c = s[2]
if "hello" in s:
    print("\"hello\" in s")

for letter in s:
    print(letter)
```

Java 写法：

```
String s = "hello";
s += " world";
s += 5;
int sLength = s.length();
String substr = s.substring(1, 5);
char c = s.charAt(2);
if (s.indexOf("hello") != -1) {
    System.out.println("\"hello\" in s");
}
for (int i = 0; i < s.length(); i++) {
    char letter = s.charAt(i);
    System.out.println(letter);
}
```

- 在 Java 里，`String` 不能直接迭代。我们要么用下标迭代并配合 `charAt`，要么把它转换成数组（马上就会讲到）。
- 在 Java 里，任何东西都可以加到 `String` 上，它会自动（隐式）转换成 `String`，不需要显式转换。
- 如果你看到黄色波浪下划线，这是 IntelliJ 在给你提供「Quick-Fix」（快速修复）建议来改进代码。在这里，它多半是建议你「Convert variable `output` from `String` to `StringBuilder`」（把变量 `output` 从 `String` 换成 `StringBuilder`），原因是「`String` concatenation `+=` in loop」（在循环里用 `+=` 拼接字符串）。接受或忽略这个建议都可以。我们**强烈建议**先弄懂这条建议再决定是否接受；这里用 `StringBuilder` 做字符串拼接是更合适的选择，因为它可变（mutable），我们会在以后的讲座里讲。

### 示例程序

Python 写法：

```
print("Hello World")
```

Java 写法：

```
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

Python 写法：

```
def is_prime(number):
    if number <= 1:
        return False
    # Check for factors from 2 up to
    # the square root of the number
    for i in range(2, int(number**0.5) + 1):
        if number % i == 0:
            return False
    return True

# Main part of the script
if is_prime(1337):
    print("1337 is prime.")
else:
    print("1337 is not prime.")
```

Java 写法：

```
public class PrimeChecker {
    public static boolean isPrime(int number) {
        if (number <= 1) {
            return false;
        }
        for (int i = 2; i <= Math.sqrt(number); i += 1) {
            if (number % i == 0) {
                return false;
            }
        }
        return true;
    }

    public static void main(String[] args) {
        if (is_prime(1337)) {
            System.out.println("1337 is prime.")
        }
        else {
            System.out.println("1337 is not prime.")
        }
    }
}
```

> **译注**：原文的这个 Java 示例有几处笔误：`main` 里调用的 `is_prime` 应为 `isPrime`；两处 `System.out.println` 语句末尾缺少分号。代码照原文保留；改正这两处之后，这个程序才能通过编译。

- 所有 Java 代码都必须放在一个**类**（class）里。关于类，以后会详细讲。
- Java 程序运行时，执行的是 `public static void main(String[] args)` 方法。这一点和 Python 不同：Python 的代码可以在函数外面直接执行。
