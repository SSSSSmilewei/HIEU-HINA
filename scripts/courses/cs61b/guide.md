# 开始之前：这门课怎么学

CS61B 的全称是 Data Structures（数据结构），是加州大学伯克利分校 CS61 系列的第二门课程，主讲教师是 Josh Hug 和 Kay Ousterhout。它以 Java 为主要语言，主线是理解、实现和分析各种数据结构——链表、数组、树、图、哈希表——并学会用工程化的方式写出能测试、能维护的代码。

## 站内的内容按哪个学期整理

站内的课程按 **2026 年春季学期**（Spring 2026）的官方课表整理，官网是 sp26.datastructur.es。每学期的官网都会换成新内容，站内的「官方原文」链接指向这一学期。

两点说明：

- 官方教材（Berkeley-CS61B/sp26-gitbook）和这一学期的讲座有几处对不上：讲座 12、30、37、40 没有配套教材章节（站内为这几讲配了依据官方幻灯片整理的讲义或复习说明）；教材第 35 章的部分内容是旧学期的。这些都在对应页面里注明了。
- 官方视频只在 YouTube 上有（英文原声），国内访问可能需要代理。

## 每个条目里有什么

| 条目 | 站内内容 |
|---|---|
| 讲座 | 讲义是官方教材对应章节的完整中文翻译（一章一页，代码和示意图说明保持原样）；没有教材章节的几讲配有依据官方幻灯片整理的讲义。每讲有官方 YouTube 视频和练手题。 |
| 讨论课（Discussion） | 纸笔练习。题目和官方解答的完整翻译都在站内，解答折叠，建议先自己做再展开对照。临近考试的几周另有官方的「考试难度练习」（Exam-Level Problems，examprep，链接在条目里）。 |
| 编程作业（Homework） | 作业说明的完整中文翻译。每次作业的起始代码从 skeleton 仓库拉取。 |
| 理论作业（Theory HW） | 作业 5、7、10 是 Gradescope 上的理论题，校外拿不到原文；站内页面写明了用什么官方材料代替练习。 |
| 小项目（Mini-Project）0–3 | 从粒子模拟器到渗流模型，项目说明的完整中文翻译。 |
| 设计项目 4、5 | 期末前的两个大项目（NGrams/WordNet 和 BYOW「建造你自己的世界」），按官方的阶段拆成多个条目，每个阶段有独立的说明页。 |
| 期末考试 | 站内有一页说明怎样使用官方考试存档（按学期、按主题两种用法）。 |

## 建议的学习顺序

按官方课表的节奏，每周两讲：先看讲座视频或读站内讲义 → 做讲座的练手题 → 做当周的讨论课（先做题再看解答）→ 做编程作业 → 轮到项目时做项目。学完整门课大约 16 周，每周投入 10–15 小时比较合适。

编程作业和小项目是这门课的核心价值，请务必亲手写完，不要抄现成的答案仓库。

## 环境和工具

- 第一次上课先做**作业 1**：它就是环境配置作业，带你安装 Git、IntelliJ IDEA、Java 25（Microsoft OpenJDK 25）并配置好作业仓库。
- 官方的作业流程是：用自己的私有 GitHub 仓库存代码，每次从 `skeleton` 远程仓库拉取起始代码，在 IntelliJ 里用 JUnit 测试。
- **不在伯克利怎么学**：作业 1 的开头有一段「本站补充」，说明校外学习者怎样用自己新建的私有仓库代替官方的 beacon 注册和 Gradescope 评分——照着做即可，作业代码请保持私有。
- 每次打开一份新作业，都要在 IntelliJ 里重新按「作业工作流程」配置一次库依赖（作业 1 的第 8 任务里有摘译）。

## 外链打不开怎么办

- 站内已经有教材、作业和项目说明的翻译，正文打不开外链不影响学习。
- 起始代码在 GitHub 仓库 Berkeley-CS61B/skeleton-sp26，国内访问 GitHub 不稳定时，可以在 gitee 等平台找镜像或重试。
- 往年考试卷放在 Google Drive 上，打不开时先做站内讨论课的题目和 examprep，同样覆盖考试题型。

## 自学怎样检验学习效果

- 每周讨论课的题目先限时自己做，再对照官方解答。
- 期中、期末之前，用官方考试存档里最近学期的试卷限时自测（期中 50 分钟、期末 3 小时），对官方解答打分。
- 编程作业的本地测试全部通过，即视为完成（官方在 Gradescope 上跑的也是同一套测试）。

## 学术诚信

官方要求不要公开发布自己的作业和项目代码（这是课程明确的规定）。请把代码保存在私有仓库里，也不要使用网上流传的解答仓库。
