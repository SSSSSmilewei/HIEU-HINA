# 期末考试：复习与往年试题

> 本页是 UC Berkeley CS61B 官方「考试存档（Exam Archive）」页面上给学生的话的中文翻译和整理，往年各学期考试的具体链接（试卷、解答、讲解录像）见本条目里的「往年试题汇总（官方）」。

## 官方考试存档里有什么

官方的考试存档（Exam Archive）收集了 CS61B 多个学期的期中考试 1、期中考试 2 和期末考试，每一学期一般提供：

- **exam**：试卷原文；
- **sols**：官方解答；
- **videos**：试题讲解录像（对试卷逐题讲解）；
- **ref**：考试时随卷发放的参考卡（reference card）；
- **clarifs**：考试当天发布的勘误和澄清（clarifications）。

某一学期没有列参考卡或澄清链接，表示官方没有留存，原文注明「请不要来问」。

## 做往年考试之前要知道的事

以下是官方存档页「Note for students solving past exams」（给学生的话）的翻译：

> 2025 年以前，每份考试都配一张专门制作的参考卡。不同学期给相似的方法起的名字有时不一样。例如，「返回但不删除最小元素」的方法，有的学期叫 `peek`，有的学期叫 `getSmallest`。在那份考试上该写哪个名字，以那学期的参考卡为准。
>
> 从 2025 年起，所有考试统一使用同一张参考卡，考试里出现的方法名现在应当是一致的。
>
> 关于考试上能用哪些方法名，记住近几年试卷首页都印着的这两句话：
>
> - 「Unless otherwise specified, you may assume that everything on the reference card has been imported.」（除另有说明外，可以假设参考卡上的所有内容都已导入。）
> - 「If an implementation detail is relevant, it will be explicitly noted in the question.」（如果某个实现细节会影响解题，题目里会明确写出来。）

**本站补充**：参考卡（reference card）是官方允许考生带进考场的一页 Java 参考资料摘要，上面列好了常用的接口和类（例如 `Deque`、`Map`、`PriorityQueue` 的方法签名）。校外学习者不必在意「能不能带进考场」，但**做往年试卷时应当对着参考卡做**——试题默认你可以直接使用参考卡上的方法，不必背方法签名。

## 官方存档的两种用法

1. **按学期**：存档上半部分是一张按学期排列的大表，每个学期一行，三列分别是期中考试 1、期中考试 2 和期末考试。复习期末，直接看「Final Exam」一列，下载最近几个学期（Fall 2025、Spring 2025、Fall 2024）的试卷和解答。
2. **按主题**：存档下半部分把多年考试的每一道题按主题归类（Java、Git、测试、链表、数组、双端队列、抽象、继承、DMS、迭代器、比较器、equals、渐近分析、并查集、ADT、二叉搜索树、B 树、红黑树、哈希、堆与优先队列、树的遍历、图的遍历、最短路径、最小生成树、字典树、排序、2048、渗流、K-D 树、归约、图的表示、比较排序、拓扑排序、基数排序、正则、位运算、博弈树、迭代、递归）。哪一块没把握，就挑那个主题下的题集中练，表里还给每道题标了难度（easy / moderate / hard）和题型（Coding 编程 / WWJD「Java 会输出什么」/ Conceptual 概念 / Testing 测试等）。

## **本站补充**：期末复习路线

1. 先把教材后半部分（排序各章、压缩、软件工程）过一遍，做每讲讨论课里没做完的题。
2. 每次讨论课都配有「考试难度练习」（Exam-Level Problems，examprep），条目链接里有原文 PDF，是官方为考试准备的针对性练习。
3. 挑最近两三个学期的期末试卷，找一段完整的 3 小时，不看任何资料限时做完，再对官方解答给自己打分；错题回到对应的教材章节重读。
4. 存档里的「videos」是官方的逐题讲解录像，适合做完对答案后看自己没想到的思路。
