# 项目 4：附加功能（LLM 辅助）

> 本页是 UC Berkeley CS61B 2026 春季官方项目说明「Project 4: LLM Augmented Optional Tasks」的中文翻译，原文见页面下方的「项目原文」。命令、代码和程序输出保持原样。

读到这一页，我们就假设你已经实现了 Hypohist 按钮。在项目的最后这一部分，我们鼓励你使用 LLM，试着做出更大的东西。

**不要在 4C 和 4D 的任何部分使用 LLM 生成的代码。LLM 生成的代码只允许用于你自己选定的「更上一层楼」功能！**（译注：原文这一句末尾多了一个「**」，是官方页面的排版残留，此处按其样式加粗处理。）

一些可能的方向：

- 添加新按钮，用有创意的方式使用一个或两个数据集。例如，你可以画出某一年所有单词的平均长度；或者做一个单词的所有 hyponym 的可视化；或者做一个打印两个单词之间最短路径的功能。
- Hyponyms 搜索会找出所有 hyponym，不管离源头多远。例如，「dog」的 hyponym 数量巨大。给前端加一个新字段 d，只找出和给定单词距离不超过 d 的单词。
- 加一个 `!` 运算符，例如有人输入「!person, leader」，你的代码就找出所有不是 person 的 leader。
- 探索数据集的统计性质，例如把出现次数（y 轴）对排名（x 轴）作图，你应该能看到齐普夫定律（Zipf's law）在起作用。
