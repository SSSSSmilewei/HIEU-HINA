## 进阶功能

项目总分中的 90 分将取决于你自选的功能，我们称之为你的「进阶分」（ambition score）。大意是：在项目的基本要求之外，我们希望你把产品再打磨一下，加一些酷炫的功能。下面是一份功能列表，每个功能值 60 分（主要功能，primary feature）或 30 分（次要功能，secondary feature）。

你需要从这两类功能中实现共 90 分的功能，其中至少一个功能必须是主要功能。超出 90 分的部分不额外给分。实现方式举例：

- 一个主要功能加一个次要功能。这是最常见的组合。
- 两个主要功能。

你的项目仍必须满足说明前面部分描述的基本要求！例如，即使你允许用户用鼠标点击操作，项目也必须仍然支持键盘移动！

**译注**：上面正文说主要功能值 60 分（合计 90 分），但本页下方的小节标题按「主要功能 80 分」、合计 110 分列示，与「验收」页的「进阶功能分（合计 110 分）」一致；两处数字对不上，无法确定哪个是笔误，请以课程公告为准。

在一些主要功能的描述下面，我们提供了 GIF 动图；这些动图在各自的进阶评分项上都能拿满分，供你参考、消除疑惑。你做的不需要和示例一模一样。

> 如果你们想同时做不同的进阶功能，我们建议用分支来管理！这里不会给出专门的指南，但可以看看 Git 指南的相关部分（[这里](https://sp26.datastructur.es/resources/using-git/#e-git-branching-advanced-git-optional)，英文）。

### 文件

对某些进阶功能，你可能要用自定义图片、音频和其他素材来装点你的世界。请确保把这些文件上传到你的项目里，并妥善组织。

另外，要用*相对文件路径*而不是绝对文件路径。例如，如果你的音乐文件 `menu_music.wav` 放在 `src` 下一个叫 `music` 的单独包里，你可以用 `music/menu_music.wav` 来引用它。

这两步都做到，任何把你的项目放到自己计算机上的人才能查看和使用你的文件。

## 主要功能（80 分）

- **视线（Line of Sight）**：做一个系统，让瓦片渲染器只在屏幕上显示头像视线范围内的瓦片。视线必须能通过按键开关。注意视线*不*应穿透墙，不过能绕过墙 / 拐角是允许的。这同时意味着视线必须足够长，让我们能判断它有没有穿过墙。下面是两个我们*不*接受的视线功能示例：

  [![line-of-sight](https://sp26.datastructur.es/assets/projects/proj5c/line-of-sight-bad1.gif)](https://sp26.datastructur.es/assets/projects/proj5c/line-of-sight-bad1.gif)

  [![line-of-sight](https://sp26.datastructur.es/assets/projects/proj5c/line-of-sight-bad2.gif)](https://sp26.datastructur.es/assets/projects/proj5c/line-of-sight-bad2.gif)

  另一方面，下面是一个可以接受的示例：

  [![line-of-sight](https://sp26.datastructur.es/assets/projects/proj5c/line-of-sight-good.gif)](https://sp26.datastructur.es/assets/projects/proj5c/line-of-sight-good.gif)

  注意，正确的做法不基于任何固定形状（示例里是菱形，但长宽固定的方框同样不允许），而是随着角色的移动而「移动」。基于以角色为中心的方框 / 菱形的解法不能得分。

- **光源（Light Sources）**：让光源能影响世界的渲染方式，且至少要有一个可以用按键开关的光源。光的强度必须随与光源距离的增加而呈梯度衰减。光源应照亮它所在房间的大部分区域，光不能穿透墙。

  [![toggle-lights](https://sp26.datastructur.es/assets/projects/proj5c/toggle-lights.gif)](https://sp26.datastructur.es/assets/projects/proj5c/toggle-lights.gif)

- **遭遇战（Encounters）**：为「遭遇战」做一个系统：头像与世界中的实体交互时出现一个新界面，遭遇战结束后返回原界面（类似《宝可梦》）。注意遭遇战结束后，世界必须恢复到遭遇战之前的状态。遭遇战期间不支持保存 / 加载也可以接受。

  [![encounter](https://sp26.datastructur.es/assets/projects/proj5c/encounter.gif)](https://sp26.datastructur.es/assets/projects/proj5c/encounter.gif)

- **撤销、重做与重置（Undo, Redo and Restart）**：用三个不同的按键实现撤销移动、重做移动和重置世界。如果最近一个动作不是撤销，重做键应不做任何事。

- **视角（Perspective）**：让用户能改变观察视角（第一人称、2.5D 等轴测、3D 等）。（我们还从没见过有人做过 2.5D 等轴测或完整 3D！N64 游戏《[Kirby 64 - The Crystal Shards](https://www.youtube.com/watch?v=5uu2TWli-_M)》就是 2.5D 等轴测世界的一个例子。）一个特别有意思的例子是 [Dorottya Urmossy 和 David Yang 在 2022 秋季的提交](https://www.youtube.com/watch?v=XJBQYucuAKc&t=94s)：2.5D 第一人称视角，即世界是 3D 的，但实体是 2D 的。

  [![perspective](https://sp26.datastructur.es/assets/projects/proj5c/perspective.gif)](https://sp26.datastructur.es/assets/projects/proj5c/perspective.gif)

- **战斗系统（Battle System）**：实现一个战斗系统，让玩家能和移动的敌人、障碍物交互。给玩家一个生命值，在地图各处摆放能恢复生命值的收集品，并创建随机移动的敌人 / 物体，它们能伤害玩家，也能被玩家伤害。

- **探索者（Explorer）**：让你的世界比预设的显示尺寸更大，让玩家可以「探索」起始世界之外的区域。渲染出的世界应在玩家越过某个点后随之移动，并且可以滚动。

- **环绕（Wrap）**：让你的世界在渲染边框处「环绕」，玩家应能从屏幕一侧进入、从相反一侧出来，反之亦然。要实现环绕，世界边缘必须有越出边界的房间，且对面一侧也有一个同样越出边界的房间，玩家才能在地板瓦片上继续行进。世界仍须遵循 B 部分的[世界要求](https://sp26.datastructur.es/proj5/proj5b/#world-requirements)，但第 10 条（房间不能越出世界边界）除外。

- **联机多人（Online Multiplayer）**：加联机多人功能，让其他用户可以加入和退出当前游戏。`java.net.Socket` 可能会派上用场。所有玩家都必须能使用交互功能（移动、保存 / 加载等）。

- **NPC**：添加 NPC 与玩家的交互和对话。让玩家能根据 NPC 和 / 或游戏状态选择不同的回应选项。如果你调用了 LLM 服务的实时 API 做出了什么酷炫的东西，请告诉我们。

- **楼层（Levels）**：实现电梯 / 可通行的楼层，带可开关的多楼层视图，或用一个明显不同的界面，并能返回主世界。

- **地形改造（Altered Terrain）**：实现让头像大幅改变世界地貌的能力，例如挖掘、触发陷阱使世界的一部分变得危险或不可通行、解开谜题使某些房间在完成目标后才可进入。

## 次要功能（30 分）

- **回放（Replay）**：让用户能「回放」最近一次存档，可视化地展示自上次创建新世界以来的所有操作。回放的最终状态必须和用户直接加载最近存档的结果完全相同。也就是说，回放结束后游戏应可以继续玩。

- **存档槽位（Save Slots）**：加多个存档槽位，通过一个新的菜单选项访问，并提供一个新的键盘快捷键，用于保存到 1 号槽位以外的槽位。注意仍然要支持默认的保存与加载行为，以与回放字符串的要求保持一致。

- **新世界（New World）**：让用户不用关闭再重新打开项目就能创建新世界，可以是探索时可以按的特殊选项，也可以是你把世界做成游戏之后的「游戏结束」状态触发的选项。

- **自定义头像（Custom Avatar）**：让你的引擎渲染图片而不是字符，并加一个菜单选项，把头像换成你自己创作的自定义图片。

- **主题（Theme）**：让你的引擎渲染图片而不是字符，并加一个菜单选项，选择世界的环境 / 主题。

- **语言（Language）**：加一个菜单选项，把界面里的所有文字换成另一种语言。默认应是英语，且必须有办法切换回英语。

- **音效（Audio）**：给你的菜单和探索界面加上好听的音乐，以及头像与世界交互时的音效。

- **小地图（Minimap）**：在某个角落加一个小地图，显示整张地图和头像的当前位置。如果你同时还实现了比屏幕更大的地图（正常情况下看不到全图），这个功能会更有意思。

- **旋转（Rotate）**：加一个旋转世界的能力，即把棋盘转过 90 度，并相应调整移动按键。

- **本地双人（Local Multiplayer）**：支持两个用户同时操作。这要求屏幕上有两个可以移动的头像，并且它们的操控方式相互独立。

- **可移动方块（Moveable Blocks）**：让玩家能通过一组按键放置和移除方块。

- **金币（Coins）**：让用户能收集金币。全部金币收集完成后，用户应回到主菜单，并可选择开始新游戏、加载以前的世界或退出。
