# 第 8 讲：Quest 复习

> 本页由海纳协会整理，用于自学时的 Quest 复习。官方这一讲是复习课，没有单独的讲义，教材也没有对应的小节。

## Quest 是什么

Quest 是学期第 4 周的一次小测验，范围是前三周的内容：

- 表达式、名字与赋值、调用表达式的求值规则（教材 1.1–1.3 节）
- `print` 与 `return` 的区别、`None`（实验 1）
- 条件语句、`while` 循环、`and` / `or` 的短路求值（教材 1.5 节、实验 2）
- 高阶函数：把函数当作参数、把函数当作返回值（教材 1.6 节）
- `lambda` 表达式和环境图（第 5 讲、讨论课 2）

## 复习方法

1. **重做「Python 会显示什么」题。** 把第 1–5 讲的练手题和实验 1、实验 2 里的这类题再做一遍，做错的题要能说清楚错在哪一步。
2. **亲手画环境图。** 讨论课 1、讨论课 2 的环境图题先在纸上画，再到 Python Tutor 里逐步运行核对。画图的固定步骤：
   - 遇到 `def`：画出函数对象（写明父帧），在当前帧里绑定函数名。
   - 遇到调用：先求运算符和运算数，再新开一个帧，标明父帧是**函数定义时所在的帧**，把形参绑定到实参。
   - 函数返回时：在帧里写上返回值。
3. **限时做往年试题。** 官方 Resources 页面有往年的考试和答案。选一份 Quest 或期中考试的前半部分，限时完成后对照答案。
4. **把讨论课里标着「考试练习」的题做完。** 例如讨论课 1 的「Repeating」、讨论课 2 的「Ups and Downs」。

## 常见的错误

- 把 `print` 的显示当成返回值：`print` 返回 `None`。
- 忘记 `and`、`or` 返回的是某一个运算数本身，而不一定是 `True` 或 `False`。
- 环境图里把新帧的父帧写成调用者所在的帧。父帧由函数**定义**的位置决定。
- 混淆「函数本身」和「调用函数得到的值」：`f` 是函数，`f()` 是调用的结果。
