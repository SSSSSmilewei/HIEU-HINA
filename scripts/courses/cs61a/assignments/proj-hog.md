# 项目 1：Hog（掷骰子游戏）

> 本页由海纳协会依据官方项目说明改写，不是原文翻译；做项目时请以官方原文为准（见页面下方的链接）。

## 游戏规则

两名玩家轮流行动，谁先在自己的回合结束时达到 `GOAL` 分（默认 100 分）谁就获胜。每个回合，当前玩家选择一次同时掷几个骰子（0 到 10 个），这一回合的得分是所有骰子点数之和。另外还有三条特殊规则：

- **Sow Sad（掷出 1）**：只要有任何一个骰子是 1，这一回合只得 1 分。例如掷 7 个骰子，其中 5 个是 1，只得 1 分；掷 4 个骰子都是 3，得 12 分。
- **Boar Brawl（不掷骰子）**：选择掷 0 个骰子时，得分是「对手分数的十位数字」与「自己分数的个位数字」之差的绝对值的 3 倍；如果结果小于 1，就得 1 分。分数只有一位数时，十位数字算 0。例如自己 21 分、对手 46 分时掷 0 个骰子，得 3 × |4 − 1| = 9 分。
- **Sus Fuss（可疑的数）**：恰好有 3 个或 4 个因数（包括 1 和它本身）的数叫「可疑的数」。掷完骰子加分之后，如果自己的总分是可疑的数，总分立刻提升到比它大的最近的质数。

## 你要写什么

起始代码已经搭好了游戏的框架、图形界面和测试，你只需要补全 `hog.py` 里的函数。

**第一阶段：游戏规则**

| 题目 | 内容 |
|---|---|
| 0 | 阅读 `dice.py`，理解「骰子」是怎样用不带参数的非纯函数表示的，回答概念题。 |
| 1 | `roll_dice`：掷指定个数的骰子，实现 Sow Sad 规则。 |
| 2 | `boar_brawl`：实现掷 0 个骰子时的得分。 |
| 3 | `take_turn`：根据掷骰子的个数，选择用 `roll_dice` 还是 `boar_brawl` 计算一回合的得分。 |
| 4 | `num_factors`、`sus_points`、`sus_update`：判断可疑的数，实现 Sus Fuss 规则。 |
| 5 | `play`：模拟整局游戏，两名玩家轮流按各自的策略行动，直到有人达到目标分数。 |

**第二阶段：策略**

| 题目 | 内容 |
|---|---|
| 6 | `always_roll`：返回「总是掷 n 个骰子」的策略（高阶函数）。 |
| 7 | `is_always_roll`：判断一个策略是不是对所有局面都掷同样个数的骰子。 |
| 8 | `make_averaged`：返回一个新函数，把原函数调用很多次并求平均值。 |
| 9 | `max_scoring_num_rolls`：用实验找出平均得分最高的掷骰个数。 |
| 10 | `boar_strategy`：当掷 0 个骰子能得到足够多的分数时就掷 0 个，否则掷默认个数。 |
| 11 | `sus_strategy`：同时考虑 Boar Brawl 和 Sus Fuss 两条规则。 |
| 12（选做） | `final_strategy`：设计你自己的最强策略。 |

## 怎么做

1. 下载起始代码（页面下方的链接），解压。
2. 每做完一题，运行 `python3 ok -q 题号 --local`（例如 `python3 ok -q 01 --local`）检查；全部做完后运行 `python3 ok --score --local`。
3. 做完第一阶段后，可以运行 `python3 hog_gui.py` 打开图形界面，和电脑对战。
4. 用到的知识：控制语句（第 3 讲）、高阶函数（第 4–5 讲）。建议先完成作业 1、作业 2 再开始。

官方允许两人合作完成项目。自学时建议先独立完成，再和同学交流思路。
