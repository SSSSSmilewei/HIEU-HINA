# 开始之前：这门课怎么学

CS61A 的全称是 Structure and Interpretation of Computer Programs（计算机程序的构造和解释），是加州大学伯克利分校 CS61 系列的第一门课程。它以 Python 为主要语言，后半学期学习 Scheme 和 SQL，主线是用函数、数据、对象和解释器四种抽象手段管理程序的复杂度。

## 站内的内容按哪个学期整理

站内的课程按 **2026 年春季学期**（Spring 2026）的官方课表整理，这是目前最新的一个已经结束的学期。授课教师是 Dan Garcia 和 Manuel A Sabin；讲座视频由 John DeNero 录制，与 2024 年各学期使用的是同一套。

官方网站 cs61a.org 每学期都会换成新学期的内容，所以站内的「官方原文」链接指向这一学期的存档页面。

## 每个条目里有什么

| 条目 | 站内内容 |
|---|---|
| 讲座 | 讲义是教材 Composing Programs 对应小节的完整中文翻译；教材没有对应内容的几讲，配有依据官方讲座整理的讲义。每讲有哔哩哔哩中英双语字幕视频和官方视频，以及练手题。 |
| 实验（Lab） | 每周一次，巩固当周的新内容。 |
| 讨论课（Discussion） | 纸笔练习，站内标为选学；期中、期末考试之前很值得做一遍。 |
| 作业（Homework） | 一共 11 次，难度高于实验。 |
| 项目（Project） | Hog、Cats、Ants、Scheme 四个项目，是这门课最有价值的部分，请务必独立完成。 |
| 考试 | 小测验（Quest）、期中考试、期末考试，可以用往年试题自测。 |

## 建议的学习顺序

每一周按这个顺序学习：看讲座视频 → 读站内讲义 → 做讲座的练手题 → 做实验 → 做作业 → 轮到项目时做项目。

按一周三讲的原始进度，学完大约需要 15 周，每周投入 10 小时左右比较合适。

## 环境和工具

- 安装 Python 3（3.10 或更新的版本）和一个编辑器，推荐 Visual Studio Code。实验 0 会带你一步步配置好。
- 官方的实验、作业和项目用 `ok` 程序在本地运行测试。自学者没有伯克利的账号，命令后面要加上 `--local`，例如 `python3 ok -q hailstone --local`。
- 讲义里的环境图可以点「在 Python Tutor 中逐步运行」查看每一步的变化。

## 外链打不开怎么办

- 视频优先看哔哩哔哩的版本；YouTube 是官方原版，作为备用。
- 课程存档托管在 GitHub Pages 上，校园网有时打不开。站内已经有讲义和题目说明，打不开也不影响学习；起始代码可以从 GitHub 仓库 lr2933/cs61a-spring-2026 下载。
