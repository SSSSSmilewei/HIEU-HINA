## 4E. 参数方程

**4E-2** 求 $x = t + 1/t$、$y = t - 1/t$ 的直角坐标方程（计算 $x^2$ 和 $y^2$）。

<details>
<summary>解答</summary>

$x^2 = t^2 + 2 + 1/t^2$，$y^2 = t^2 - 2 + 1/t^2$。两式相减，得到双曲线

$$
x^2 - y^2 = 4.
$$

</details>

**4E-3** 求 $x = 1 + \sin t$、$y = 4 + \cos t$ 的直角坐标方程。

<details>
<summary>解答</summary>

$$
(x - 1)^2 + (y - 4)^2 = \sin^2t + \cos^2t = 1 \qquad (\text{圆}).
$$

</details>

**4E-8** 中午 12 点，一只蜗牛从一个敞开的钟面的中心出发。它沿着时针匀速爬行，在下午 1 点到达时针的末端。时针长 1 米。在某个合理的 $xy$ 坐标系中，写出蜗牛在时刻 $t$ 的位置的参数方程。

<details>
<summary>解答</summary>

用角 $\theta$ 表示时针的尖端 $Q$：$Q = (\cos\theta, \sin\theta)$（单位是米）。

接下来用时间参数 $t$（小时）表示 $\theta$。我们有：$t = 0$ 时 $\theta = \pi/2$，$t = 1$ 时 $\theta = \pi/3$，并且 $\theta$ 随 $t$ 线性减小，所以

$$
\frac{\theta - \frac\pi2}{t - 0} = \frac{\frac\pi3 - \frac\pi2}{1 - 0} \;\Longrightarrow\; \theta = \frac\pi2 - \frac\pi6t.
$$

> 图：钟面，圆心为原点；时针从原点指向 $Q$，与 $x$ 轴的夹角为 $\theta$，蜗牛 $P$ 在时针上。

最后，蜗牛的位置 $P$ 是

$$
P = (t\cos\theta, t\sin\theta),
$$

其中 $t$ 从 0 增大到 1。所以

$$
x = t\cos\left(\frac\pi2 - \frac\pi6t\right) = t\sin\frac\pi6t, \qquad y = t\sin\left(\frac\pi2 - \frac\pi6t\right) = t\cos\frac\pi6t.
$$

</details>

## 4F. 弧长

**4F-1d** 求曲线 $y = \frac13(2 + x^2)^{3/2}$，$1 \le x \le 2$ 的弧长。

<details>
<summary>解答</summary>

$y' = x(2 + x^2)^{1/2}$。因此 $ds = \sqrt{1 + 2x^2 + x^4}\,dx = (1 + x^2)\,dx$，

$$
\text{弧长} = \int_1^2 (1 + x^2)\,dx = x + \frac{x^3}{3}\Big|_1^2 = \frac{10}{3}.
$$

</details>

**4F-4** 求曲线 $x = t^2$、$y = t^3$，$0 \le t \le 2$ 的长度。

<details>
<summary>解答</summary>

$ds = \sqrt{(dx/dt)^2 + (dy/dt)^2}\,dt = \sqrt{4t^2 + 9t^4}\,dt$。因此

$$
\text{弧长} = \int_0^2 \sqrt{4t^2 + 9t^4}\,dt = \int_0^2 (4 + 9t^2)^{1/2}t\,dt = \frac{1}{27}(4 + 9t^2)^{3/2}\Big|_0^2 = \frac{40^{3/2} - 8}{27}.
$$

</details>

**4F-5** 求习题 4E-2 中参数曲线在 $1 \le t \le 2$ 上的长度的积分。尽可能化简被积函数，但不必计算。

<details>
<summary>解答</summary>

$dx/dt = 1 - 1/t^2$，$dy/dt = 1 + 1/t^2$。于是

$$
ds = \sqrt{(dx/dt)^2 + (dy/dt)^2}\,dt = \sqrt{2 + 2/t^4}\,dt, \qquad \text{弧长} = \int_1^2 \sqrt{2 + 2/t^4}\,dt.
$$

</details>

**4F-8** 求曲线 $x = e^t\cos t$、$y = e^t\sin t$，$0 \le t \le 10$ 的长度。

<details>
<summary>解答</summary>

$dx/dt = e^t(\cos t - \sin t)$，$dy/dt = e^t(\cos t + \sin t)$。

$$
ds = \sqrt{e^{2t}(\cos t - \sin t)^2 + e^{2t}(\cos t + \sin t)^2}\,dt = e^t\sqrt{2\cos^2t + 2\sin^2t}\,dt = \sqrt2e^t\,dt.
$$

因此弧长是

$$
\int_0^{10} \sqrt2e^t\,dt = \sqrt2(e^{10} - 1).
$$

</details>

## 4G. 曲面面积

**4G-2** 求 $y = 1 - 2x$ 在第一象限的那一段绕 $x$ 轴旋转所得曲面的面积。

<details>
<summary>解答</summary>

上下限是 $0 \le x \le 1/2$。$ds = \sqrt5\,dx$，所以

$$
dA = 2\pi y\,ds = 2\pi(1 - 2x)\sqrt5\,dx \;\Longrightarrow\; A = 2\pi\sqrt5\int_0^{1/2} (1 - 2x)\,dx = \frac{\sqrt5\pi}{2}.
$$

（这是一个底面半径 1、母线长 $\frac{\sqrt5}{2}$ 的圆锥的侧面积 $\pi \cdot 1 \cdot \frac{\sqrt5}{2}$，可以用来检验。）

</details>

**4G-5** 求 $y = x^2$，$0 \le x \le 4$ 绕 $y$ 轴旋转所得曲面的面积。

<details>
<summary>解答</summary>

$x = \sqrt y$，$dx/dy = \dfrac{1}{2\sqrt y}$，$ds = \sqrt{1 + \dfrac{1}{4y}}\,dy$。$x$ 从 0 到 4 对应 $y$ 从 0 到 16：

$$
\begin{aligned}
A &= \int 2\pi x\,ds = \int_0^{16} 2\pi\sqrt y\sqrt{1 + \frac{1}{4y}}\,dy = \int_0^{16} 2\pi\sqrt{y + \frac14}\,dy \\
&= \frac{4\pi}{3}\left(y + \frac14\right)^{3/2}\Big|_0^{16} = \frac{4\pi}{3}\left(\left(\frac{65}{4}\right)^{3/2} - \left(\frac14\right)^{3/2}\right) = \frac\pi6\left(65\sqrt{65} - 1\right) \approx 273.9.\end{aligned}
$$

也可以直接对 $x$ 积分：$A = \displaystyle\int_0^4 2\pi x\sqrt{1 + 4x^2}\,dx = \frac\pi6(1 + 4x^2)^{3/2}\Big|_0^4$，结果相同。

（译注：原文的解答把 $y$ 的上限写成了 2，得到 $\frac{13\pi}{3}$，那对应的是 $0 \le x \le \sqrt2$。按题目的 $0 \le x \le 4$，$y$ 应从 0 到 16，译文已更正，结果经数值积分核对过。）

</details>
