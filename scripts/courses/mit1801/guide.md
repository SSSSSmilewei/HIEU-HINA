# 学习指南

> 本页由海纳协会编写，介绍怎样在站内学完 MIT 18.01SC 单变量微积分（Single Variable Calculus，2010 年秋季开放课程版）。课程材料 © MIT OpenCourseWare，CC BY-NC-SA 4.0。

## 这门课是什么

18.01 是麻省理工学院一年级第一学期的必修课，讲一元函数的微分和积分及其应用。18.01SC 是它的「自学版」（SC 即 Scholar，学者版）：把 2006 年秋季 David Jerison 教授的课堂录像剪成一个个几分钟的片段，每个片段配一页讲义，再加上例题、习题讲解视频、习题课和考试，按自学的节奏编排。

**先修要求**：高中代数和三角函数。学过一点微积分会更轻松，但不是必须的。

## 课程结构

全课分 5 个单元，每个单元分成几个部分（A、B、C），每部分是若干「节」（session），每部分最后有一次习题课，每个单元最后有复习和考试：

| 单元 | 内容 |
|---|---|
| 单元 1：微分 | 导数的定义、求导法则、隐函数求导、指数与对数 |
| 单元 2：微分的应用 | 线性与二次近似、作图、最优化、相关变化率、牛顿法、中值定理、原函数、微分方程 |
| 单元 3：定积分及其应用 | 黎曼和、微积分基本定理、面积、体积、平均值、概率、数值积分 |
| 单元 4：积分技巧 | 三角积分、三角代换、部分分式、分部积分、弧长、旋转面面积、参数方程、极坐标 |
| 单元 5：探索无穷 | 洛必达法则、反常积分、无穷级数、泰勒级数 |

## 每一节怎么学

1. **看讲座片段**（条目里的「讲座片段 1、2……」，英文，可以打开 YouTube 的自动翻译字幕），同时或之后读站内的「讲义」页——讲义是每个片段配套讲义的中文翻译，内容和录像一一对应。
2. **做例题**：打开「例题与解答」页，先自己做，再展开解答对照。有些例题要配合「交互演示（Mathlet）」做。
3. **做练手题**：页面下方的练手题改编自本节的讲义和例题，做对会记进热力图。
4. 想多看一种讲法，可以看「习题讲解视频」（助教讲题，英文）。

每部分结束后做一次「习题课」，每个单元结束后先看复习课，再找一段完整的时间做考试，最后对照解答给自己打分。
