# 例题：用垫圈法求旋转体体积

> 本页是 MIT 开放式课程 18.01SC 本节例题（Worked Example）及其解答的中文翻译，原文见页面下方的「例题原文（PDF）」和「例题解答原文（PDF）」，© MIT OpenCourseWare，CC BY-NC-SA 4.0。建议先自己做，再展开解答。

**问题**：通过对变量 $y$ 积分，求由 $y = 0$、$x = 4$ 和 $y = \sqrt x$ 围成的区域绕直线 $x = 6$ 旋转所形成的旋转体的体积。

<details>
<summary>解答</summary>

这道题在习题讲解视频中是用柱壳法解的。这里用**垫圈法**。

先画出区域的草图；见图 1。

> 图 1：要旋转的区域：曲线 $y = \sqrt x$、$x$ 轴和直线 $x = 4$ 围成的区域；旋转轴是在它右边的直线 $x = 6$。

这个区域要绕直线 $x = 6$ 旋转。结果是一个甜甜圈形的立体；因为要旋转的区域没有一直延伸到直线 $x = 6$，所以旋转体中间会有一个洞。

计算这个立体体积最简单的方法，是用柱壳法、对 $x$ 积分；习题讲解视频里讲的就是这个。也可以把立体水平切成一片片垫圈形的薄片，把垫圈的体积加起来。

每个垫圈的高是 $dy$，内半径为 $r$，外半径为 $R \ge r$。在这个例子里，内半径由直线 $x = 4$ 和 $x = 6$ 之间的距离决定，所以 $r = 2$。外半径 $R$ 是 $y = \sqrt x$ 的图像到直线 $x = 6$ 的水平距离。这个距离是 $y$ 的函数；在甜甜圈的底部它很大（6），在顶部很小（2）。

因为要对变量 $y$ 积分，需要从 $y = \sqrt x$ 解出用 $y$ 表示的 $x$：

$$
x = y^2.
$$

外半径是这个 $x$ 位置到 $x = 6$ 的（正的）距离，所以 $R = 6 - y^2$。

每个垫圈的体积，是半径为 $R$ 的圆盘挖去中间半径为 $r$ 的圆盘后的体积：

$$
\begin{aligned}
dV &= (\text{半径为 } R \text{ 的圆盘体积}) - (\text{半径为 } r \text{ 的圆盘体积}) = \pi R^2\,dy - \pi r^2\,dy \\
&= \pi(R^2 - r^2)\,dy = \pi\bigl((6 - y^2)^2 - 2^2\bigr)\,dy = \pi(36 - 12y^2 + y^4 - 4)\,dy = \pi(32 - 12y^2 + y^4)\,dy.
\end{aligned}
$$

立体的体积由垫圈体积的黎曼和给出；也就是由一个积分给出。立体的底在 $y = 0$，最高点在曲线 $y = \sqrt x$ 与直线 $x = 4$ 相交处，所以高为 $2 = \sqrt4$。

$$
\text{体积} = \int_{y=0}^{y=2} dV = \int_0^2 \pi(32 - 12y^2 + y^4)\,dy = \pi\left[32y - 4y^3 + \frac{y^5}{5}\right]_0^2 = \pi\left(64 - 32 + \frac{32}{5}\right) - 0 = \frac{192}{5}\pi.
$$

为了检验结果，我们注意到它接近 $36\pi$，大致是一个截面积为 9、半径（旋转半径）为 2 的垫圈的旋转体积。
