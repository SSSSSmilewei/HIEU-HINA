# 例题：我们需要商法则吗？

> 本页是 MIT 开放式课程 18.01SC 本节例题（Worked Example）及其解答的中文翻译，原文见页面下方的「例题原文（PDF）」和「例题解答原文（PDF）」，© MIT OpenCourseWare，CC BY-NC-SA 4.0。建议先自己做，再展开解答。

商法则可能不好记，而且有些同学用负指数比用分式更顺手。这个练习告诉我们怎样把链式法则和乘积法则结合起来，代替商法则。

a) 用商法则求 $\dfrac{x^3}{x + 1}$ 的导数。

b) 用乘积法则和链式法则求 $x^3 \cdot (x + 1)^{-1}$ 的导数。注意 $x^3 \cdot (x + 1)^{-1} = \dfrac{x^3}{x + 1}$。

c) 用链式法则和乘积法则（不用商法则）证明 $u(x)(v(x))^{-1}$ 的导数等于 $\dfrac{u'(x)v(x) - u(x)v'(x)}{(v(x))^2}$。

<details>
<summary>解答</summary>

**a)** 商法则告诉我们

$$
\left(\frac{u(x)}{v(x)}\right)' = \frac{u'(x)v(x) - u(x)v'(x)}{(v(x))^2}.
$$

这里 $u(x) = x^3$，$u'(x) = 3x^2$，$v(x) = x + 1$，$v'(x) = 1$。所以

$$
\left(\frac{x^3}{x + 1}\right)' = \frac{3x^2(x + 1) - x^3 \cdot 1}{(x + 1)^2} = \frac{3x^3 + 3x^2 - x^3}{(x + 1)^2} = \frac{2x^3 + 3x^2}{(x + 1)^2}.
$$

**b)** 乘积法则告诉我们 $(u(x) \cdot v(x))' = u'(x)v(x) + u(x)v'(x)$。同样 $u(x) = x^3$、$u'(x) = 3x^2$，但现在 $v(x) = (x + 1)^{-1}$。用链式法则求出 $v'(x) = -1 \cdot (x + 1)^{-2} \cdot 1 = -(x + 1)^{-2}$。

现在用乘积法则求出

$$
\bigl(x^3 \cdot (x + 1)^{-1}\bigr)' = 3x^2(x + 1)^{-1} + x^3\bigl(-(x + 1)^{-2}\bigr) = 3x^2(x + 1)^{-1} - x^3(x + 1)^{-2}.
$$

虽然 $x^3 \cdot (x + 1)^{-1} = \dfrac{x^3}{x + 1}$，两种写法求出的导数看起来很不一样。事实上它们在代数上是等价的；看起来不同但等价的答案在微积分中很常见。用一些基本的代数就能说明两个答案等价：

$$
\begin{aligned}
3x^2(x + 1)^{-1} - x^3(x + 1)^{-2} &= 3x^2(x + 1)^{-2}(x + 1) - x^3(x + 1)^{-2} && (\text{凑出公因式 } (x + 1)^{-2}) \\
&= \bigl(3x^2(x + 1) - x^3\bigr)(x + 1)^{-2} && (\text{提出 } (x + 1)^{-2}) \\
&= \frac{3x^2(x + 1) - x^3}{(x + 1)^2} = \frac{2x^3 + 3x^2}{(x + 1)^2} && (\text{去掉负指数}).
\end{aligned}
$$

**c)** 可以把上一题的解法当作提纲。这里 $u(x) = f(x)$，$u'(x) = f'(x)$，$v(x) = (g(x))^{-1}$，由链式法则 $v'(x) = -(g(x))^{-2}g'(x)$。于是

$$
\begin{aligned}
\bigl(f(x)(g(x))^{-1}\bigr)' &= f'(x)(g(x))^{-1} + f(x)\bigl(-(g(x))^{-2}g'(x)\bigr) \\
&= f'(x)(g(x))^{-1} - f(x)(g(x))^{-2}g'(x) \\
&= f'(x)(g(x))^{-2}g(x) - f(x)g'(x)(g(x))^{-2} \\
&= \bigl[f'(x)g(x) - f(x)g'(x)\bigr](g(x))^{-2} \\
&= \frac{f'(x)g(x) - f(x)g'(x)}{(g(x))^2}.
\end{aligned}
$$

注意，时间允许的话，在做涉及链式法则的题时，可以用这种求导方法来检查结果。
