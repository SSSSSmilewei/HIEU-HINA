# 例题：用部分分式积分

用部分分式法计算积分

$$
\int \frac{x^2 + 2x + 3}{(x + 1)(x + 2)(x + 3)}\,dx.
$$

<details>
<summary>解答</summary>

先看能不能把分子因式分解、约掉分母里的某些项；不能。因为分母里的项都是一次的，不必再分解。分子是二次多项式，分母是三次，所以不需要做多项式长除法。

部分分式分解设为

$$
\frac{x^2 + 2x + 3}{(x + 1)(x + 2)(x + 3)} = \frac{A}{x + 1} + \frac{B}{x + 2} + \frac{C}{x + 3}.
$$

现在用遮盖法，先求 $A$：遮住 $x + 1$ 以及不含 $x + 1$ 的各项，再代入使 $x + 1$ 等于 0 的值 $x = -1$，得到

$$
\frac{(-1)^2 + 2 \cdot (-1) + 3}{(-1 + 2)(-1 + 3)} = 1 = A.
$$

对 $B$ 和 $C$ 重复这一过程：

$$
\frac{(-2)^2 + 2(-2) + 3}{(-2 + 1)(-2 + 3)} = B \;\Longrightarrow\; B = -3,
$$

$$
\frac{(-3)^2 + 2(-3) + 3}{(-3 + 1)(-3 + 2)} = C \;\Longrightarrow\; C = 3.
$$

得出

$$
\frac{x^2 + 2x + 3}{(x + 1)(x + 2)(x + 3)} = \frac{1}{x + 1} - \frac{3}{x + 2} + \frac{3}{x + 3}.
$$

代入 $x = 0$，得到 $\dfrac12 = 1 - \dfrac32 + 1$，所以这个分解大概是对的。

现在可以把它拆成三个相对简单的积分。下面用代换 $u = x + 3$ 详细算出其中一个；另外两个类似：

$$
\int \frac{3}{x + 3}\,dx = 3\int \frac1u\,du = 3\ln|u| + c = 3\ln|x + 3| + c.
$$

综上，

$$
\int \frac{x^2 + 2x + 3}{(x + 1)(x + 2)(x + 3)}\,dx = \int \left(\frac{1}{x + 1} - \frac{3}{x + 2} + \frac{3}{x + 3}\right)dx = \ln|x + 1| - 3\ln|x + 2| + 3\ln|x + 3| + c.
$$

可以试着求导来检验，但那会直接变成验证部分分式分解是否正确——一件费时的事。
