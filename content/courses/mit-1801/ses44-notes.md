## 片段 1：例子：f(x) = x²

Jerison 教授只做了一个把定积分作为极限来计算的简单例子，因为用这种方法计算积分要做大量艰苦的工作。

这个例子里我们用第一条有意思的曲线 $f(x) = x^2$，起点 $a = 0$。为了看出规律，我们让 $b$ 任意——算完之后愿意的话可以再换成具体的值。

先画出 $f(x)$ 的图像，标出要计算面积的区域。

> 图 1：用三个矩形近似 $\displaystyle\int_0^b f(x)\,dx$：每个矩形的右上角落在抛物线上。

接着，把从 0 到 $b$ 的区间分成 $n$ 份；在这门课里各份总是等长的。图 1 是 $n = 3$ 的例子。每一份构成一个矩形的底。矩形的顶与图像相接；Jerison 教授选择让矩形的右上角落在图像上。因此，矩形面积之和会比曲线下方的面积稍大一点。

接下来求矩形的面积。矩形的好处是面积很好算——底乘以高就行。因为 $n$ 个矩形的底一样长，每个矩形的底长都是 $\dfrac bn$。每个矩形的高由 $f(x_i) = x_i^2$ 给出，其中 $x_i$ 是底的右端点。

第一个矩形的底是 $\left[0, \frac bn\right]$，所以它的高是 $\left(\frac bn\right)^2$，面积是 $\left(\frac bn\right)^3$。其他矩形的信息见下表。

| $x$（底的右端点） | $f(x)$（矩形的高） |
|---|---|
| $\dfrac bn$ | $\left(\dfrac bn\right)^2$ |
| $\dfrac{2b}{n}$ | $\left(\dfrac{2b}{n}\right)^2$ |
| $\dfrac{3b}{n}$ | $\left(\dfrac{3b}{n}\right)^2$ |
| $\vdots$ | $\vdots$ |
| $\dfrac{nb}{n} = b$ | $b^2$ |

现在很容易求出各个矩形的面积；把它们加起来，就得到曲线下方面积的一个近似：

$$
\underbrace{\left(\frac bn\right)}_{\text{底}}\underbrace{\left(\frac bn\right)^2}_{\text{高}} + \left(\frac bn\right)\left(\frac{2b}{n}\right)^2 + \left(\frac bn\right)\left(\frac{3b}{n}\right)^2 + \cdots + \left(\frac bn\right)\left(\frac{nb}{n}\right)^2.
$$

这很复杂。我们先化简它，再朝着求 $n$ 趋于无穷（即矩形的底变成无穷小）时的极限努力。结果是，求极限比求矩形面积之和容易；这正是我们学微积分的原因。

首先，可以提出 $\left(\frac bn\right)^3$：

$$
\left(\frac bn\right)\left(\frac bn\right)^2 + \left(\frac bn\right)\left(\frac{2b}{n}\right)^2 + \cdots + \left(\frac bn\right)\left(\frac{nb}{n}\right)^2 = \frac{b^3}{n^3}\left(1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2\right).
$$

我们要取 $n$ 趋于无穷时的极限。难办的是和 $1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2$。我们用一个几何「技巧」画一张代表这个量的图。

**平方和的几何算法**

想象你在建一座金字塔。金字塔的底层是由 $n^2$ 个立方块组成的 $n \times n$ 正方形。上一层是 $(n - 1) \times (n - 1)$，有 $(n - 1)^2$ 块。从上往下看，金字塔是一圈圈同心的正方形。从侧面看，金字塔像一个由高为 1、长为 $n$、$n - 1$ 等等的矩形叠成的三角形。这个三角形左右两边的斜率是 2 和 $-2$。

这座金字塔的体积是 $n^2 + (n - 1)^2 + \cdots + 3^2 + 2^2 + 1^2$，正好等于定积分里那个难办的和。这个体积比完全包含在阶梯金字塔里面的最大的普通金字塔——底面边长为 $n$、高为 $n$——的体积稍大。我们知道那个里面的金字塔的体积是 $\frac13 \cdot \text{底面积} \cdot \text{高}$，即 $\frac13n^2 \cdot n$。所以

$$
\frac13n^3 < 1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2.
$$

> 图 2：阶梯金字塔的俯视图（一圈圈同心正方形）和侧视图（台阶状的三角形），边长都是 $n$。

我们把等于阶梯金字塔体积的那个难办的和，与能放进它里面的最大普通金字塔的体积 $\frac13n^3$ 作了比较。这是朝着把难办的和换成简单得多的东西迈出的一步。

接下来，把阶梯金字塔的体积和能装下它的最小普通金字塔的体积作比较。那个金字塔底面边长为 $n + 1$、高为 $n + 1$，所以体积是 $\frac13(n + 1)^3$。因此

$$
\frac13n^3 < 1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2 < \frac13(n + 1)^3.
$$

现在把各项都除以 $n^3$，得到

$$
\frac13 < \frac{1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2}{n^3} < \frac13\frac{(n + 1)^3}{n^3} = \frac13\left(1 + \frac1n\right)^3.
$$

令 $n$ 趋于无穷，这个不等式的左右两边都趋于 $\frac13$，所以中间的式子

$$
\frac{1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2}{n^3} \longrightarrow \frac13 \qquad (n \to \infty).
$$

$x^2$ 图像下方矩形面积之和是

$$
\frac{b^3}{n^3}\left(1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2\right).
$$

当 $n$ 趋于无穷时，这个面积趋于 $\dfrac{b^3}{3}$。所以 $f(x) = x^2$ 的图像与区间 $[0, b]$ 之间的总面积是

$$
\int_0^b x^2\,dx = \frac{b^3}{3}.
$$

**问**：为什么这一步我们把 $\left(\frac bn\right)^3$ 先放在一边？

**答**：部分原因是我们知道目标是什么。我们理解 $\left(\frac bn\right)^3$ 这个量。然而那个难办的和 $(1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2)$ 以一种我们不完全理解的方式越来越大。所以我们把难办的和单独拿出来，集中处理它。这样做之后，我们发现它和 $n^3$ 非常非常相似，和 $\frac13n^3$ 更相似。一旦理解了这一点，就可以把它用回原来的式子，约掉 $n^3$，得到结果。

分析这类和时你总是这样做：把你理解的部分提出来，最后剩下一个像这样的和。每次遇到这样的和，你都应该预料到会出现这种情况。

总结一下，我们求曲线下方面积的步骤是：

1. 画出函数的图像。
2. 把区间分成 $n$ 个长为 $\dfrac{b - a}{n}$ 的小区间。
3. 计算矩形的高 $f\left(a + \dfrac{i(b - a)}{n}\right)$。
4. 计算矩形的面积。
5. 把矩形的面积加起来。
6. 求这个和在 $n$ 趋于无穷时的极限。

## 片段 2：求和记号

你一定注意到了，处理像 $1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2$ 这样的和极其麻烦；它实在太长，没法好好处理。数学家对这类计算有一种简写，它不会让算术变容易，但确实让这些和写起来更容易。

一般的记号是

$$
\sum_{i=1}^n a_i = a_1 + a_2 + \cdots + a_n.
$$

求和符号 $\Sigma$ 是大写的希腊字母西格玛。例如，

$$
\frac{1^2 + 2^2 + 3^2 + \cdots + (n - 1)^2 + n^2}{n^3} = \frac{1}{n^3}\sum_{i=1}^n i^2.
$$

我们刚刚证明了

$$
\lim_{n \to \infty} \frac{1}{n^3}\sum_{i=1}^n i^2 = \frac13.
$$

用求和记号时，会有一个用 $i$ 描述每个被加项 $a_i$ 的公式；例如 $a_i = i^2$。式子 $\displaystyle\sum_{i=1}^n a_i$ 只是各项 $a_i$ 之和的缩写。

我们遇到的另一个难办的和是

$$
\left(\frac bn\right)\left(\frac bn\right)^2 + \left(\frac bn\right)\left(\frac{2b}{n}\right)^2 + \left(\frac bn\right)\left(\frac{3b}{n}\right)^2 + \cdots + \left(\frac bn\right)\left(\frac{nb}{n}\right)^2.
$$

用求和记号可以把它改写成

$$
\sum_{i=1}^n \left(\frac bn\right)\left(\frac{ib}{n}\right)^2.
$$

前面我们从这个和里提出了 $\left(\frac bn\right)^3$；用新记号也可以这样做：

$$
\sum_{i=1}^n \left(\frac bn\right)\left(\frac{ib}{n}\right)^2 = \frac{b^3}{n^3}\sum_{i=1}^n i^2.
$$

这些记号只是让我们的笔记紧凑一点。概念还是一样，乱糟糟的东西还藏在地毯下面，但记号至少能让它写得下。
