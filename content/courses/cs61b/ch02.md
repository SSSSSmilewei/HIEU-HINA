### 静态方法与非静态方法

**静态方法**

Java 里的所有代码都必须是某个类的一部分（或者是类似于类的东西的一部分，以后会学到）。大多数代码写在方法里。来看一个例子：

```java
public class Dog {
    public static void makeNoise() {
        System.out.println("Bark!");
    }
}
```

如果试着运行 `Dog` 类，只会得到一条错误信息：

```
$ java Dog
Error: Main method not found in class Dog, please define the main method as:
       public static void main(String[] args)
```

我们定义的 `Dog` 类什么也不做。我们只是定义了 `Dog` **能**做的一件事，即发出叫声。要真正运行这个类，要么像第 1.1 节那样给 `Dog` 类加一个 main 方法；要么另外创建一个 [`DogLauncher`](https://www.youtube.com/watch?v=Q-LE-jJQLTM) 类，由它来运行 `Dog` 类里的方法。例如，看下面的程序：

```java
public class DogLauncher {
    public static void main(String[] args) {
        Dog.makeNoise();
    }
}
```

```
$ java DogLauncher
Bark!
```

使用另一个类的类，有时被称为那个类的「客户端」（client），即 `DogLauncher` 是 `Dog` 的客户端。这两种做法没有哪种更好：有些情况下给 `Dog` 加 main 方法更好，另一些情况下创建 `DogLauncher` 这样的客户端类更好。随着整门课的练习增多，两种做法各自的优点会逐渐清楚。

**实例变量与对象的实例化**

不是所有的狗都一样。有的狗喜欢没完没了地尖声叫唤，有的狗则洪亮地吠叫，让每个听到它们美妙叫声的人都感到快乐。我们常常编写程序来模拟我们所处世界的种种特征，而 Java 的语法正是为了方便做这种模拟而设计的。

要表示狗的种种不同，一种办法是为每种狗单独建一个类。

```java
public class TinyDog {
    public static void makeNoise() {
        System.out.println("yip yip yip yip");
    }
}

public class MalamuteDog {
    public static void makeNoise() {
        System.out.println("arooooooooooooooo!");
    }
}
```

你以前应该见过，类可以被实例化，实例可以保存数据。这就引出一种更自然的做法：创建 `Dog` 类的实例，让 `Dog` 方法的行为取决于具体某只 `Dog` 的属性。为了说得更具体，看下面这个类：

```java
public class Dog {
    public int weightInPounds;

    public void makeNoise() {
        if (weightInPounds < 10) {
            System.out.println("yipyipyip!");
        } else if (weightInPounds < 30) {
            System.out.println("bark. bark.");
        } else {
            System.out.println("woof!");
        }
    }    
}
```

使用这种 Dog 的一个例子：

```java
public class DogLauncher {
    public static void main(String[] args) {
        Dog d;
        d = new Dog();
        d.weightInPounds = 20;
        d.makeNoise();
    }
}
```

运行时，这个程序会创建一只体重为 20 的 `Dog`，这只 `Dog` 很快就会发出一声漂亮的「bark. bark.」。

几个要点和术语：

* Java 里的**对象**（`Object`）是任何一个类的实例。
* `Dog` 类有自己的变量，也叫*实例变量*或*非静态变量*。它们必须在类里声明，这和 Python、Matlab 这样能在运行时添加新变量的语言不同。
* 我们在 `Dog` 类里创建的方法没有 `static` 关键字。这样的方法叫作*实例方法*或*非静态方法*。
* 要调用 `makeNoise` 方法，必须先用 `new` 关键字*实例化*一只 `Dog`，再让这只具体的 `Dog` 叫。换句话说，我们调用的是 `d.makeNoise()`，而不是 `Dog.makeNoise()`。
* 对象实例化之后，可以*赋值*给一个类型合适的、*已声明*的变量，例如 `d = new Dog();`。
* 类的变量和方法也叫类的*成员*。
* 用*点号写法*访问类的成员。

**Java 里的构造函数**

你以前大概见过，在面向对象的语言里，我们通常用*构造函数*（constructor）来创建对象：

```java
public class DogLauncher {
    public static void main(String[] args) {
        Dog d = new Dog(20);
        d.makeNoise();
    }
}
```

这里实例化是带参数的，省去了手动敲出可能很多条实例变量赋值语句的时间和麻烦。要支持这种写法，只需要给 Dog 类加一个「构造函数」，如下所示：

```java
public class Dog {
    public int weightInPounds;

    public Dog(int w) {
        weightInPounds = w;
    }

    public void makeNoise() {
        if (weightInPounds < 10) {
            System.out.println("yipyipyip!");
        } else if (weightInPounds < 30) {
            System.out.println("bark. bark.");
        } else {
            System.out.println("woof!");
        }    
    }
}
```

每当我们用 `new` 关键字和一个整数参数创建 `Dog` 时，签名为 `public Dog(int w)` 的构造函数就会被调用。对学过 Python 的同学来说，构造函数和 `__init__` 方法非常相似。

**数组的实例化，对象数组**

正如在 HW0 里看到的，Java 里的数组也用 new 关键字实例化。例如：

```java
public class ArrayDemo {
    public static void main(String[] args) {
        /* Create an array of five integers. */
        int[] someArray = new int[5];
        someArray[0] = 3;
        someArray[1] = 4;
    }
}
```

类似地，可以在 Java 里创建存放已实例化对象的数组，例如：

```java
public class DogArrayDemo {
    public static void main(String[] args) {
        /* Create an array of two dogs. */
        Dog[] dogs = new Dog[2];
        dogs[0] = new Dog(8);
        dogs[1] = new Dog(20);

        /* Yipping will result, since dogs[0] has weight 8. */
        dogs[0].makeNoise();
    }
}
```

注意 new 有两种不同的用法：一次用来创建能存放两个 `Dog` 对象的数组，两次用来创建每只真正的 `Dog`。

### 类方法与实例方法

Java 允许我们定义两种方法：

* 类方法，也叫静态方法。
* 实例方法，也叫非静态方法。

实例方法是只能由类的某个具体实例执行的动作。静态方法是由类本身执行的动作。两者在不同情况下都有用。举一个静态方法的例子，`Math` 类提供了 `sqrt` 方法。因为它是静态的，可以这样调用：

```java
x = Math.sqrt(100);
```

如果 `sqrt` 是实例方法，就得用下面这种别扭的写法。幸好 `sqrt` 是静态方法，真实的程序里不必这样写。

```java
Math m = new Math();
x = m.sqrt(100);
```

有时候，一个类同时有实例方法和静态方法是合理的。例如，假设想能比较两只狗。一种办法是加一个比较 Dog 的静态方法。

```java
public static Dog maxDog(Dog d1, Dog d2) {
    if (d1.weightInPounds > d2.weightInPounds) {
        return d1;
    }
    return d2;
}
```

可以这样调用这个方法：

```java
Dog d = new Dog(15);
Dog d2 = new Dog(100);
Dog.maxDog(d, d2);
```

注意，因为这是静态方法，我们是用类名调用的。

也可以把 `maxDog` 实现成非静态方法，例如：

```java
public Dog maxDog(Dog d2) {
    if (this.weightInPounds > d2.weightInPounds) {
        return this;
    }
    return d2;
}
```

上面用关键字 `this` 指代当前对象。可以这样调用这个方法：

```java
Dog d = new Dog(15);
Dog d2 = new Dog(100);
d.maxDog(d2);
```

这里我们是用一个具体的实例变量来调用方法。

**静态变量**

类有时有静态变量会很有用。这些是类本身固有的属性，而不是实例的属性。例如，我们可以记录狗的学名（双名法名称）是「Canis familiaris」：

```java
public class Dog {
    public int weightInPounds;
    public static String binomen = "Canis familiaris";
    ...
}
```

静态变量应该用类名访问，而不是用某个具体实例访问，例如应该用 `Dog.binomen`，而不是 `d.binomen`。

虽然 Java 在技术上允许用实例名访问静态变量，但这是不好的风格，容易让人困惑，而且在我看来是 Java 设计者的一个错误。

### public static void main(String[] args)

学到这里，是时候揭开我们一直在用的 main 方法声明的神秘面纱了。把它拆开来看：

* `public`：到目前为止，我们所有的方法都以这个关键字开头。
* `static`：它是静态方法，不和任何具体的实例关联。
* `void`：它没有返回类型。
* `main`：这是方法的名字。
* `String[] args`：这是传给 main 方法的一个参数。

**命令行参数**

因为 main 是由 Java 解释器本身而不是别的 Java 类调用的，提供这些参数是解释器的工作。它们通常指的是命令行参数。例如，看下面的程序 `ArgsDemo`：

```java
public class ArgsDemo {
    public static void main(String[] args) {
        System.out.println(args[0]);
    }
}
```

这个程序打印第 0 个命令行参数，例如：

```
$ java ArgsDemo these are command line arguments
these
```

在上面的例子里，`args` 是一个字符串数组，各项是 {"these", "are", "command", "line", "arguments"}。
