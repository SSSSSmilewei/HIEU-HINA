# 项目 3：CS61CPU

> 本页是海纳协会按官方课表整理的中文要点，不是官方讲义的翻译。视频、幻灯片和阅读材料见本页的链接。

## 这个项目做什么

在 Logisim 里搭出一个能运行 RISC-V 指令的处理器：先做算术逻辑单元和寄存器堆（A 部分），再做完整的数据通路、控制器和两级流水线（B 部分）。

## 怎么做

- 到本页下方的链接打开官方项目说明，按其中的步骤获取起始代码。
- 官方的起始代码通过 GitHub Classroom 发给选课学生；自学的同学如果取不到，可以使用课程介绍里列出的往年学期（2020 秋季）作业备份。
- 项目说明很长，建议先通读一遍，再对照测试一步一步完成。
