# 第 7 讲：C 的抽象数据类型

英文标题：C Abstract Data Types

> 本页是海纳协会按官方课表整理的中文要点，不是官方讲义的翻译。视频、幻灯片和阅读材料见本页的链接。

## 本讲要点

- 结构体（struct）把几个字段组合成一个新类型；`typedef` 给类型起一个新名字。
- 通过指针访问结构体的字段写作 `p->field`，等价于 `(*p).field`。
- 为了对齐（alignment），编译器会在字段之间填充字节，所以 `sizeof(struct)` 可能大于各字段大小之和。
- 用结构体加一组操作函数可以实现链表这样的抽象数据类型；头文件里声明接口，源文件里写实现。
- 这一讲还介绍了 IEC 前缀：Ki = 2^10，Mi = 2^20，Gi = 2^30。
