# 第 37 讲：虚拟内存（二）

英文标题：Virtual Memory II

> 本页是海纳协会按官方课表整理的中文要点，不是官方讲义的翻译。视频、幻灯片和阅读材料见本页的链接。

## 本讲要点

- 页表项（page table entry）里有有效位、物理页号，以及读、写、执行等权限位。
- 每次访存都去查页表太慢，所以用快表（Translation Lookaside Buffer）缓存最近用过的翻译结果。
- 一次访存的流程：先查快表；快表缺失就查页表；页表显示这一页不在内存里就是缺页，交给操作系统处理。
- 单级页表对很大的地址空间来说太占内存，实际使用多级页表，只为用到的部分建立下一级页表。
- 缺页要访问磁盘，比一次普通的访存慢好几个数量级，所以缺页率必须非常低。
