# 第 19 讲：功能模块与算术逻辑单元

英文标题：Blocks and ALU

> 本页是海纳协会按官方课表整理的中文要点，不是官方讲义的翻译。视频、幻灯片和阅读材料见本页的链接。

## 本讲要点

- 多路选择器（multiplexer）根据选择信号从几个输入里选一个输出；有 2^n 个输入时需要 n 位选择信号。
- 算术逻辑单元（Arithmetic Logic Unit）在一个模块里完成加、减、与、或等运算，由控制信号选择输出哪一种结果。
- 一位全加器有三个输入（两个加数位和进位输入）和两个输出（和、进位输出）；把 N 个全加器串起来就是 N 位加法器。
- 减法可以复用加法器：把第二个操作数按位取反，再把最低位的进位输入设为 1，这正是补码的求相反数。
