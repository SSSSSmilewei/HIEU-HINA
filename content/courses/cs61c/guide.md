# 开始之前：这门课怎么学

CS61C 的全称是 Great Ideas in Computer Architecture (Machine Structures)（计算机体系结构的伟大思想：机器结构），是加州大学伯克利分校 CS61 系列的第三门课。它回答一个问题：你写的 C 程序是怎样一步步变成机器码，并在处理器上运行起来的。

## 站内的内容是按哪个学期整理的

站内的课程内容按 **2026 年秋季学期**（Fall 2026）的官方课表整理，授课教师是 Dan Garcia。这一学期还在进行，最后几周的实验和项目以官方课程网站为准。

学期结束后，官方会把旧学期的页面移到需要伯克利账号的服务器上，届时 `cs61c.org/fa26/` 开头的链接可能失效。官方课程笔记（notes.cs61c.org）是独立的网站，不受影响；课程介绍里也列出了往年学期的备份。

## 每个条目是什么

| 条目 | 说明 |
|---|---|
| 讲座 | 40 讲（其中 3 讲是客座讲座，站内标为选学）。站内每一讲有中文要点和练手题，链接里有官方课程笔记和幻灯片。 |
| 讨论课（Discussion） | 纸笔练习，有题目和参考答案的 PDF，以及 2024 春季学期的讲解视频。站内标为选学，但很适合用来巩固。 |
| 实验（Lab） | 上机练习：C 语言调试、RISC-V 汇编、Logisim 电路、并行编程。 |
| 作业（Homework） | 官方作业在 PrairieLearn 平台上，只对选课学生开放。自学可以用讨论课题目和往年试题代替。 |
| 项目（Project） | snek（C 语言）、CS61Classify（RISC-V 汇编）、CS61CPU（Logisim 处理器），以及选做的 61kaChow（性能优化）。 |
| 考试 | 小测验（Quest）、期中考试的两个部分、期末考试。往年试题在官方网站的 Past Exams 页面。 |

## 建议的学习顺序

每一讲：读官方课程笔记（或看讲座录像）→ 做站内的练手题 → 做当周的讨论课题目 → 做实验 → 轮到项目时做项目。

全课程分成五个部分：数的表示与 C 语言（第 1–8 讲）、RISC-V 汇编（第 9–15 讲）、数字电路与处理器（第 16–25 讲）、缓存（第 26–29 讲）、并行与虚拟内存（第 30–37 讲）。

## 先修要求

需要会写程序，并且了解基本的数据结构（链表、数组）。建议先学完 CS61A 和 CS61B，或者先学完 CS50x。

## 环境和工具

- C 语言部分需要 gcc、gdb 和 Valgrind。Windows 上建议使用 WSL（适用于 Linux 的 Windows 子系统）。
- RISC-V 部分使用官方的在线模拟器 Venus，在浏览器里就能运行。
- 数字电路部分使用 Logisim Evolution，实验 5 会带你安装。
- 官方的参考卡（Reference Card）汇总了 RISC-V 指令和编码，写汇编时常备在手边。
