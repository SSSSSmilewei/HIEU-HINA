# 第 26 讲：缓存（一）：性能

英文标题：Caches I: Performance

## 本讲要点

- 处理器比主存快得多，每次访存都去主存会把处理器拖慢；缓存（cache）是处理器和主存之间一小块很快的存储器。
- 存储层次：寄存器 → 各级缓存 → 主存 → 磁盘，越往下越大、越慢、越便宜。
- 局部性原理（locality）：时间局部性（刚用过的数据很可能马上再用）、空间局部性（用过的数据附近的数据很可能马上会用）。
- 访问的数据在缓存里叫命中（hit），不在叫缺失（miss）；缺失时要到下一级去取，花的时间叫缺失代价（miss penalty）。
- 平均访存时间（Average Memory Access Time）= 命中时间 + 缺失率 × 缺失代价。
