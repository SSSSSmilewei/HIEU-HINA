# 第 1 讲：课程介绍与计算机体系结构的伟大思想

英文标题：Intro, Great Ideas

> 本页是海纳协会按官方课表整理的中文要点，不是官方讲义的翻译。视频、幻灯片和阅读材料见本页的链接。

## 本讲要点

- CS61C 讲的是软件和硬件的交界：C 程序怎样变成汇编和机器码，机器码又怎样在处理器上执行。
- 计算机用层层抽象组织起来：高级语言 → 汇编语言 → 机器语言 → 处理器的电路 → 逻辑门 → 晶体管。
- 课程反复出现的几个伟大思想：抽象、摩尔定律、局部性原理与存储层次、并行、性能的测量与改进、用冗余获得可靠性。
- 学完之后应当能解释一个 C 程序为什么快或者慢，并且能动手让它变快。
