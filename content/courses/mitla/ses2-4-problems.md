## 习题 17.1

（教材第 4.4 节第 10 题 b）标准正交的向量自动线性无关。

用矩阵来证明：证明 $Qx = 0$ 能推出 $x = 0$。由于 $Q$ 可能是长方形矩阵，你可以用 $Q^T$，但不能用 $Q^{-1}$。

<details>
<summary>解答</summary>

按定义，$Q$ 是各列标准正交的矩阵，所以 $Q^T Q = I$（$Q$ 可以是长方形的）。于是

$$
Qx = 0 \;\Longrightarrow\; Q^T Q x = Q^T 0 \;\Longrightarrow\; Ix = 0 \;\Longrightarrow\; x = 0.
$$

因此 $Q$ 的零空间只有零向量，$Q$ 的各列线性无关：各列没有任何非零的线性组合等于零向量。所以标准正交的向量自动线性无关。

</details>

## 习题 17.2

（教材第 4.4 节第 18 题）对下面的向量 $a$、$b$、$c$ 用 Gram-Schmidt 过程，求出张成同一空间的正交向量 $A$、$B$、$C$：

$$
a = (1, -1, 0, 0), \quad b = (0, 1, -1, 0), \quad c = (0, 0, 1, -1).
$$

证明 $\{A, B, C\}$ 和 $\{a, b, c\}$ 都是所有垂直于 $d = (1, 1, 1, 1)$ 的向量组成的空间的基。

<details>
<summary>解答</summary>

对 $a$、$b$、$c$ 做 Gram-Schmidt。首先令

$$
A = a = (1, -1, 0, 0).
$$

接着求 $B$：

$$
B = b - \frac{A^T b}{A^T A} A = (0, 1, -1, 0) + \frac{1}{2}(1, -1, 0, 0) = \left(\frac12, \frac12, -1, 0\right).
$$

然后求 $C$：

$$
C = c - \frac{A^T c}{A^T A} A - \frac{B^T c}{B^T B} B = (0, 0, 1, -1) + \frac{2}{3}\left(\frac12, \frac12, -1, 0\right) = \left(\frac13, \frac13, \frac13, -1\right).
$$

由第一题可知，$\{A, B, C\}$ 中的向量线性无关，并且每个都与 $(1, 1, 1, 1)$ 正交。垂直于 $d$ 的向量组成的空间是三维的（因为 $(1, 1, 1, 1)$ 的行空间是一维的，而行空间与零空间的维数之和是 4）。所以 $\{A, B, C\}$ 是垂直于 $d$ 的向量组成的空间的一组基。

同样，$\{a, b, c\}$ 也是这个空间的一组基，因为这三个向量线性无关、都与 $(1, 1, 1, 1)$ 正交，而且恰好有三个。

</details>
