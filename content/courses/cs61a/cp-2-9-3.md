## 2.9.3 集合

除了列表、元组和字典，Python 还有第四种内置容器类型：集合（set）。集合字面量沿用了它的数学记法：用大括号把元素括起来。重复的元素在构造集合时会被移除。集合是无序集合，所以打印出来的顺序可能和字面量中的元素顺序不同。

```py
>>> s = {3, 2, 1, 4, 4}
>>> s
{1, 2, 3, 4}
```

Python 的集合支持多种操作，包括成员测试、长度计算，以及并集和交集这些标准集合运算。

```py
>>> 3 in s
True
>>> len(s)
4
>>> s.union({1, 5})
{1, 2, 3, 4, 5}
>>> s.intersection({6, 5, 4, 3})
{3, 4}
```

除了 `union` 和 `intersection`，Python 的集合还支持其他一些方法。谓词 `isdisjoint`、`issubset` 和 `issuperset` 用于集合之间的比较。集合是可变的，可以用 `add`、`remove`、`discard` 和 `pop` 一次改动一个元素。还有一些方法支持一次改动多个元素，比如 `clear` 和 `update`。到了课程的这个阶段，Python 关于集合的 [documentation for sets](http://docs.python.org/py3k/library/stdtypes.html#set) 应该足够容易理解，可以补全其中的细节。

**实现集合。** 抽象地说，集合是一组互不相同的对象，支持成员测试、并集、交集和邻接。把一个元素邻接到一个集合上，会返回一个新集合，它包含原集合的所有元素以及这个新元素（前提是新元素与原有元素不同）。并集和交集分别返回出现在其中一个集合或同时出现在两个集合中的元素所组成的集合。和任何数据抽象一样，只要某种集合表示提供了这一组行为，我们就可以自由地在这种表示上实现任何函数。

在本节剩下的部分，我们考虑三种表示各不相同的集合实现方法。我们分析集合运算的增长阶，以此刻画这些不同表示的效率。我们会用到本节前面的 `Link` 和 `Tree` 类，它们能为基本集合运算提供简单而优雅的递归解法。

**作为无序序列的集合。** 表示集合的一种方法是把它表示成一个元素不重复出现的序列。空集合用空序列表示。成员测试会递归地遍历列表。

```py
>>> def empty(s):
        return s is Link.empty
>>> def set_contains(s, v):
        """当且仅当 set s 包含 v 时返回 True。"""
        if empty(s):
            return False
        elif s.first == v:
            return True
        else:
            return set_contains(s.rest, v)
>>> s = Link(4, Link(1, Link(5)))
>>> set_contains(s, 2)
False
>>> set_contains(s, 5)
True
```

这个 `set_contains` 实现平均需要 $Θ(n)$ 时间来测试一个元素是否属于集合，其中 n 是集合 s 的大小。用这个线性时间的成员测试函数，我们也能在线性时间内把一个元素邻接到集合上。

```py
>>> def adjoin_set(s, v):
        """返回一个包含 s 的所有元素和元素 v 的所有元素的集合。"""
        if set_contains(s, v):
            return s
        else:
            return Link(v, s)
>>> t = adjoin_set(s, 2)
>>> t
Link(2, Link(4, Link(1, Link(5))))
```

设计一种表示时，我们应当关心的问题之一就是**效率**。求两个集合 `set1` 和 `set2` 的交集也需要成员测试，但这一次，`set1` 的每个元素都必须在 `set2` 中测试是否属于，这导致步骤数呈二次增长，对于大小为 n 的两个集合是 $Θ(n^2)$。

```py
>>> def intersect_set(set1, set2):
        """返回一个集合，包含 set1 和 set2 中的公共元素。"""
        return keep_if_link(set1, lambda v: set_contains(set2, v))
>>> intersect_set(t, apply_to_all_link(s, square))
Link(4, Link(1))
```

求两个集合的并集时，我们必须小心，不要把任何元素包含两次。`union_set` 函数也需要线性次数的成员测试，整个过程同样包含 $Θ(n^2)$ 步。

```py
>>> def union_set(set1, set2):
        """返回一个集合，包含 set1 和 set2 中的所有元素。"""
        set1_not_set2 = keep_if_link(set1, lambda v: not set_contains(set2, v))
        return extend_link(set1_not_set2, set2)
>>> union_set(t, s)
Link(2, Link(4, Link(1, Link(5))))
```

**作为有序序列的集合。** 加快集合运算的一个办法是改变表示，让集合元素按递增顺序排列。要做到这一点，我们需要能比较两个对象、判断哪个更大的办法。在 Python 中，许多不同类型的对象都可以用 `<` 和 `>` 操作符比较，但在本例中我们只讨论数字。我们按递增顺序列出元素，来表示一组数字。

排序的一个好处体现在 `set_contains` 中：检查某个对象是否存在时，我们不再需要扫描整个集合。如果遇到的集合元素比要找的元素大，就知道这个元素不在集合中：

```py
>>> def set_contains(s, v):
        if empty(s) or s.first > v:
            return False
        elif s.first == v:
            return True
        else:
            return set_contains(s.rest, v)
>>> u = Link(1, Link(4, Link(5)))
>>> set_contains(u, 0)
False
>>> set_contains(u, 4)
True
```

这样能省下多少步？最坏情况下，要找的元素可能是集合中最大的那个，步数就和无序表示一样。另一方面，如果我们查找许多大小不同的元素，可以预料：有时能在列表开头附近就停止搜索，有时仍然要检查列表的大部分。平均而言，我们预计需要检查集合中大约一半的元素。因此，所需的平均步数约为 $\frac{n}{2}$。这仍然是 $Θ(n)$ 增长阶，但比起之前的实现，实践中确实能省下一些时间。

重新实现 `intersect_set`，我们能获得更可观的加速。在无序表示中，这个操作需要 $Θ(n^2)$ 步，因为我们要为 `set1` 的每个元素完整扫描一遍 `set2`。但有了有序表示，我们可以用更聪明的办法：同时遍历两个集合，跟踪 `set1` 中的元素 `e1` 和 `set2` 中的元素 `e2`。当 `e1` 和 `e2` 相等时，就把这个元素放进交集。

不过，假设 `e1` 小于 `e2`。由于 `e2` 比 `set2` 剩余的元素都小，我们可以立刻断定：`e1` 不可能出现在 `set2` 的剩余部分中，因此不在交集里。于是我们不再需要考虑 `e1`，把它丢弃，继续处理 `set1` 的下一个元素。当 `e2 < e1` 时，用类似的逻辑推进 `set2` 的元素。函数如下：

```py
>>> def intersect_set(set1, set2):
        if empty(set1) or empty(set2):
            return Link.empty
        else:
            e1, e2 = set1.first, set2.first
            if e1 == e2:
                return Link(e1, intersect_set(set1.rest, set2.rest))
            elif e1 < e2:
                return intersect_set(set1.rest, set2)
            elif e2 < e1:
                return intersect_set(set1, set2.rest)
>>> intersect_set(s, s.rest)
Link(4, Link(5))
```

为了估计这个过程所需的步数，注意每一步我们都会缩小至少一个集合的大小。因此，所需的步数最多是 `set1` 和 `set2` 大小之和，而不是无序表示那样的大小之积。这是 $Θ(n)$ 增长阶，而不是 $Θ(n^2)$——这是相当大的加速，即使对中等规模的集合也很有意义。例如，两个大小为 100 的集合求交集大约需要 200 步，而无序表示需要 10,000 步。

用有序序列表示的集合，邻接和并集也可以在线性时间内计算。这些实现留作练习。

**作为二叉搜索树的集合。** 把集合元素排成**恰好有两个分支的树**，能比有序序列做得更好。树根处的 `entry` 保存集合的一个元素。左分支中的条目包含所有小于根处元素的元素。右分支中的条目包含所有大于根处元素的元素。下图展示了表示集合 `{1,3,5,7,9,11}` 的一些树。同一个集合可以用许多不同的树来表示。在所有二叉搜索树中，左分支的所有元素都小于根处的条目，右子树的所有元素都大于根处的条目。

![用二叉搜索树表示集合](https://cdn.jsdelivr.net/gh/csfive/composing-programs-zh@8943e57c5e890da12f373d109d40fd9beea14271/sicp/public/sicp/set_trees.png)

树表示的好处在于：假设我们想检查一个值 `v` 是否包含在集合中。我们先比较 `v` 和 `entry`。如果 `v` 更小，就知道只需搜索左子树；如果 `v` 更大，就只需搜索右子树。此时，如果树是「平衡的」，这两个子树的大小都大约是原树的一半。这样，我们一步就把搜索大小为 $n$ 的树的问题，化简为搜索大小为 $\frac{n}{2}$ 的树的问题。由于树的大小每一步都减半，可以预料搜索树所需的步数按 $Θ(log\ n)$ 增长。对于大型集合，这比之前的表示快得多。下面这个 `set_contains` 函数就利用了树结构集合的排序结构：

```py
>>> def set_contains(s, v):
        if s is None:
            return False
        elif s.entry == v:
            return True
        elif s.entry < v:
            return set_contains(s.right, v)
        elif s.entry > v:
            return set_contains(s.left, v)
```

把元素邻接到集合上的实现与搜索类似，也需要 $Θ(log\ n)$ 步。我们把 `v` 与 `entry` 比较，判断 `v` 该加到右分支还是左分支；把 `v` 邻接到合适的分支后，再把这个新构造的分支与原来的 `entry` 和另一个分支拼接起来。如果 `v` 等于 `entry`，就直接返回这个节点。如果要把 `v` 邻接到一棵空树上，我们就生成一棵树，它的 `entry` 是 `v`，左右分支都为空。函数如下：

```py
>>> def adjoin_set(s, v):
        if s is None:
            return Tree(v)
        elif s.entry == v:
            return s
        elif s.entry < v:
            return Tree(s.entry, s.left, adjoin_set(s.right, v))
        elif s.entry > v:
            return Tree(s.entry, adjoin_set(s.left, v), s.right)
>>> adjoin_set(adjoin_set(adjoin_set(None, 2), 3), 1)
Tree(2, Tree(1), Tree(3))
```

我们说搜索树能在对数步数内完成，前提是树「平衡」，也就是每棵树的左子树和右子树元素数量大致相同，因此每个子树包含大约一半的父树元素。但我们怎么确定构造出的树一定平衡呢？即使从一棵平衡树出发，用 `adjoin_set` 添加元素也可能产生不平衡的结果。新邻接元素的位置取决于它与集合中已有元素的比较结果，所以可以预料，如果我们「随机」添加元素，树平均而言会趋于平衡。

但这没有保证。例如，从空集合开始，依次邻接数字 1 到 7，最后会得到一棵高度不平衡的树，其中所有左子树都为空，因此它比起简单的有序列表没有任何优势。解决这个问题的一个办法，是定义一个操作，把任意树转换成元素相同的平衡树。我们可以在每进行几次 `adjoin_set` 操作之后执行一次这种转换，让集合保持平衡。

把树结构集合转换成有序列表再转换回来，就能在线性时间内完成交集和并集操作。具体细节留作练习。

**Python 的集合实现。** Python 内置的 `set` 类型内部并不使用上面任何一种表示。它用的是一种基于哈希（hashing）技术的表示，能提供常数时间的成员测试和邻接操作，这是另一门课程的主题。内置的 Python 集合不能包含可变数据类型，比如列表、字典或其他集合。为了支持嵌套集合，Python 还内置了一个不可变的 `frozenset` 类，它与 `set` 类共享方法，但不包含修改方法和操作符。
