# 第 36 讲：趣味编程（选学）

> 本页由海纳协会整理。官方这一讲是选学内容，不在考试范围内，没有公开的幻灯片和讲义，内容以当学期的课堂为准。

这一讲展示怎样用一学期学到的东西写出有趣的程序。学有余力时，可以从下面几个方向挑一个动手做：

- **Scheme 递归艺术**：用 Scheme 的海龟图形（教材 3.2.5 节）画分形图案，参加官方的 Scheme 递归艺术比赛（项目页里的「Scheme Contest」），并看看往届作品。
- **游戏策略**：给项目 1 Hog 写一个更强的策略，和最终策略对比胜率。
- **数据分析**：用 SQL 或 Python 分析一份自己感兴趣的公开数据集。
- **自己的小工具**：用 Python 写一个能解决自己日常小问题的程序，例如整理文件、统计记账数据。

做完之后，可以在协会里分享你的作品。
