# 2.3.1–2.3.3 序列

> 本页是 CS61A 教材 Composing Programs 第 2.3 节的中文翻译。原文：[23-sequences](https://www.composingprograms.com/pages/23-sequences.html)（John DeNero，CC BY-NC-SA 许可）；译文：[csfive/composing-programs-zh](https://composingprograms.netlify.app/2/3)。

**序列**（sequence）是**有序**的值集合。序列是计算机科学中一种强大而基础的抽象。序列并不是某个特定内置类型或抽象数据表示的实例，而是多种不同数据类型共有的一组行为。也就是说，序列有很多种，但它们都拥有共同的行为。具体来说：

- **长度**（Length）：序列的长度是有限的，空序列的长度为 0
- **元素选择**（Element selection）：序列拥有与每一个小于其长度的**非负整数索引**相对应的元素，索引从 0 开始表示第一个元素

Python 包含多种属于序列的原生数据类型，其中最重要的是**列表**（list）。

## 2.3.1 列表

列表值是一种**长度任意的序列**。列表有大量内置行为，也有表达这些行为的专门语法。我们已经见过列表字面量（求值为 `list` 实例），以及元素选择表达式（求值为列表中的某个值）。内置的 `len` 函数返回序列的长度。在下例中，`digits` 是一个包含四个元素的列表。索引 3 处的元素是 8。

```python
>>> digits = [1, 8, 2, 8]
>>> len(digits)
4
>>> digits[3]
8
```

此外，列表可以相加，也可以乘以整数。对序列来说，加法和乘法**并不是把元素相加或相乘**，而是把**序列本身**组合、复制。也就是说，`operator` 模块中的 `add` 函数（以及 `+` 运算符）会生成一个新列表，把相加的两个参数拼接起来。`operator` 中的 `mul` 函数（以及 `*` 运算符）接收一个列表和一个整数 `k`，返回由原列表重复 `k` 次构成的新列表。

```python
>>> [2, 7] + digits * 2
[2, 7, 1, 8, 2, 8, 1, 8, 2, 8]
```

列表中可以有**任何值**，包括另一个列表。要想选出嵌套列表里更深处的元素，可以把元素选择反复用几次。

```python
>>> pairs = [[10, 20], [30, 40]]
>>> pairs[1]
[30, 40]
>>> pairs[1][0]
30
```


## 2.3.2 序列遍历

很多时候，我们想**遍历**序列的元素，依次对每个元素做点什么。这种模式太常见了，Python 专门提供了一条处理序列数据的控制语句：`for` 语句。

考虑这样一个问题：数出某个值在序列里出现了多少次。我们可以用 `while` 循环写一个函数来计算这个次数。

```python
>>> def count(s, value):
        """统计 value 在序列 s 中出现的次数。"""
        total, index = 0, 0
        while index < len(s):
            if s[index] == value:
                total = total + 1
            index = index + 1
        return total

>>> count(digits, 8)
2
```

Python 的 `for` 语句可以直接遍历元素值，从而简化这个函数体，根本不用引入 `index` 这个名称。

```python
>>> def count(s, value):
        """统计在序列 s 中出现了多少次值为 value 的元素"""
        total = 0
        for elem in s:
            if elem == value:
                total = total + 1
        return total

>>> count(digits, 8)
2
```

`for` 语句由一个子句组成，形式如下：

```python
for <name> in <expression>:
    <suite>
```

`for` 语句的执行过程如下：

1. 求值头部（header）的 `<expression>`，它必须产生一个**可迭代**（iterable）值
2. 对该可迭代值中的每个元素，按顺序执行：
   - 在当前帧中将 `<name>` 绑定到该值
   - 执行语句组 `<suite>`

这个执行过程提到了可迭代值。列表是一种序列，而序列是可迭代值。它们的元素按顺序处理。Python 还包含其他可迭代类型，但我们目前先把重点放在序列上；「可迭代」一词的通用定义出现在第 4 章关于迭代器的部分。

这个求值过程有一个重要推论：`for` 语句执行完毕后，`<name>` 会绑定到序列的**最后一个元素**上。`for` 循环又给语句更新环境增加了一种方式。

**序列解包**（Sequence unpacking）。程序中一种常见的模式，是使用一个元素本身也是序列的序列，且所有内部序列长度固定。`for` 语句的头部可以包含多个名称，从而把每个元素序列「解包」到各自的元素中。例如，我们可能有一个由双元素列表组成的列表：

```python
>>> pairs = [[1, 2], [2, 2], [2, 3], [4, 4]]
```

并希望数出其中第一个元素和第二个元素相同的「对」有多少个。

```python
>>> same_count = 0
```

下面的 `for` 语句头部有两个名称，它们会分别绑定到每个「对」的第一个和第二个元素上。

```python
>>> same_count = 0
>>> for x, y in pairs:
        if x == y:
            same_count = same_count + 1

>>> same_count
2
```

把定长序列中的多个值绑定到多个名称，这种模式叫序列解包；它和我们在把多个值绑定到多个名称的赋值语句里见到的模式是一样的。

**范围**（Ranges）：`range` 是 Python 中另一种内置的序列类型，用于表示整数范围。范围用 `range` 创建，它接受两个整数参数：第一个是起始数字，第二个是目标范围末位数字的**后一位**。

```python
>>> range(1, 10)  # [1, 10)，包括 1，但不包括 10
range(1, 10)
```

对范围调用 `list` 构造函数，会求值得到一个包含该范围所有元素的列表，这样就能方便地查看元素。

```python
>>> list(range(5, 8))
[5, 6, 7]
```

如果只给一个参数，它会被解释为从 0 开始的范围的结束值（后一位）。

```python
>>> list(range(4))
[0, 1, 2, 3]
```

范围常用作 `for` 头部的表达式，用来指定语句组应**执行的次数**。如果 `for` 头部中的名称在语句组里没用到，惯例是用单个下划线字符当名称：

```python
>>> for _ in range(3):
        print('Go Bears!')

Go Bears!
Go Bears!
Go Bears!
```

对解释器来说，这个下划线只是环境中的另一个名称；但在程序员之间，它有**约定俗成的含义**，表示该名称**不会出现在以后的任何表达式中**。


## 2.3.3 序列处理

序列是如此常见的一种复合数据形式，以至于整个程序常常就围绕这一个抽象来组织。把序列当作输入和输出的模块化组件，可以随意混搭来完成数据处理。把一串简单、专一的序列处理操作串成流水线，就能定义出复杂的组件。

**列表推导式**（List Comprehensions）：许多序列处理操作都可以这样描述：对序列中的每个元素求值同一个固定表达式，把结果值收集到一个结果序列里。在 Python 中，列表推导式就是做这类计算的表达式。

```python
>>> odds = [1, 3, 5, 7, 9]
>>> [x+1 for x in odds]
[2, 4, 6, 8, 10]
```

上面的 `for` 关键字不是 `for` 语句的一部分，而是列表推导式的一部分，因为它被包在方括号里。子表达式 `x+1` 会在 `x` 依次绑定到 `odds` 的每个元素时求值，得到的值收集到一个列表中。

另一种常见的序列处理操作，是选出满足某些条件的值的子集。列表推导式也能表达这种模式，比如选出 `odds` 中所有能整除 `25` 的元素。

```python
>>> [x for x in odds if 25 % x == 0]
[1, 5]
```

列表推导式的一般形式是：

```python
[<映射表达式> for <名称> in <序列表达式> if <过滤表达式>]
```

要求值一个列表推导式，Python 先求值 `<序列表达式>`，它必须返回一个可迭代值。然后依次处理每个元素：把元素值绑定到 `<名称>`，求值过滤表达式，如果结果为真，就求值映射表达式。映射表达式的值收集到一个列表里。

**聚合**（Aggregation）：序列处理中第三种常见模式，是把序列里的所有值聚合为单个值。内置函数 `sum`、`min` 和 `max` 都是聚合函数的例子。

把「对每个元素求值一个表达式」「选出元素子集」「聚合元素」这几种模式组合起来，就能用序列处理的思路解决问题。

完全数（Perfect Number）是一个正整数，它等于所有因子之和。`n` 的因子是指小于 `n` 且能整除 `n` 的正整数。列出 `n` 的因子，可以用列表推导式表示。

```python
>>> def divisors(n):
        return [1] + [x for x in range(2, n) if n % x == 0]

>>> divisors(4)
[1, 2]
>>> divisors(12)
[1, 2, 3, 4, 6]
```

有了 `divisors`，我们就能用另一个列表推导式算出 1 到 1000 之间的所有完全数。（通常认为 1 也是完全数，尽管按我们的 `divisors` 定义它并不符合。）

```python
>>> [n for n in range(1, 1000) if sum(divisors(n)) == n]
[1, 6, 28, 496]
```

我们还可以复用 `divisors` 的定义来解决另一个问题：给定面积，求整数边长矩形的最小周长。矩形的面积是宽乘以高。所以给定面积和高，就能算出宽。我们可以断言宽和高都能整除面积，以确保边长是整数。

```python
>>> def width(area, height):
        assert area % height == 0
        return area // height
```

矩形的周长是它各条边长之和。

```python
>>> def perimeter(width, height):
        return 2 * width + 2 * height
```

整数边长的矩形，其高必定是面积的因子。把所有可能的高都考虑一遍，就能算出最小周长。

```python
>>> def minimum_perimeter(area):
        heights = divisors(area)
        perimeters = [perimeter(width(area, h), h) for h in heights]
        return min(perimeters)

>>> area = 80
>>> width(area, 5)
16
>>> perimeter(16, 5)
42
>>> perimeter(10, 8)
36
>>> minimum_perimeter(area)
36
>>> [minimum_perimeter(n) for n in range(1, 10)]
[4, 6, 8, 8, 12, 10, 16, 12, 12]
```

**高阶函数**：我们在序列处理中观察到的这些常见模式，可以用高阶函数来表达。首先，「对序列中每个元素求值一个表达式」可以表示为把一个函数应用到每个元素上。

```python
>>> def apply_to_all(map_fn, s):
        return [map_fn(x) for x in s]
```

「只保留某些表达式为真的元素」，也可以表示为对每个元素应用一个函数。

```python
>>> def keep_if(filter_fn, s):
        return [x for x in s if filter_fn(x)]
```

最后，很多形式的聚合都可以表示为：把一个双参数函数反复应用到目前已经**归约**（reduced）的值和下一个元素上。

```python
>>> def reduce(reduce_fn, s, initial):
        reduced = initial
        for x in s:
            reduced = reduce_fn(reduced, x)
        return reduced
```

例如，可以用 `reduce` 把序列里所有元素乘在一起。用 `mul` 作 `reduce_fn`、`1` 作 `initial`，就能用它求出一串数字的乘积。

```python
>>> reduce(mul, [2, 4, 8], 1)
64
```

用这些高阶函数同样能找到完全数。

```python
>>> def divisors_of(n):
        divides_n = lambda x: n % x == 0
        return [1] + keep_if(divides_n, range(2, n))

>>> divisors_of(12)
[1, 2, 3, 4, 6]
>>> from operator import add
>>> def sum_of_divisors(n):
        return reduce(add, divisors_of(n), 0)

>>> def perfect(n):
        return sum_of_divisors(n) == n

>>> keep_if(perfect, range(1, 1000))
[1, 6, 28, 496]
```

**惯用名称**（Conventional Names）：在计算机科学界，`apply_to_all` 更常见的名字是 `map`（映射），`keep_if` 更常见的名字是 `filter`（过滤）。Python 内置的 `map` 和 `filter` 是这两个函数的泛化版本，它们不直接返回列表。这两个函数会在第 4 章讨论。上面的定义，等同于对内置 `map` 和 `filter` 调用的结果再调用 `list` 构造函数。

```python
>>> apply_to_all = lambda map_fn, s: list(map(map_fn, s))
>>> keep_if = lambda filter_fn, s: list(filter(filter_fn, s))
```

`reduce` 函数内置在 Python 标准库的 `functools` 模块里。在这个版本中，`initial` 参数是可选的。

```python
>>> from functools import reduce
>>> from operator import mul
>>> def product(s):
        return reduce(mul, s)

>>> product([1, 2, 3, 4, 5])
120
```

在 Python 程序里，直接用列表推导式比用高阶函数更常见，但这两种序列处理方法都有人用。
