# 4.3.1–4.3.2 声明式编程

> 本页是 CS61A 教材 Composing Programs 第 4.3 节的中文翻译。原文：[43-declarative-programming](https://www.composingprograms.com/pages/43-declarative-programming.html)（John DeNero，CC BY-NC-SA 许可）；译文：[csfive/composing-programs-zh](https://composingprograms.netlify.app/4/3)。

除了流之外，数据值通常存放在称为数据库（database）的大型存储库中。数据库包含一个数据存储区，其中存放数据值，还提供检索和转换这些值的接口。存储在数据库中的每个值称为记录（record）。结构相似的记录归入同一张表（table）。记录通过查询（query）来检索和转换，查询是查询语言中的语句。时至今日，使用最广泛的查询语言是结构化查询语言（Structured Query Language），简称 SQL（读作「sequel」）。

SQL 是声明式编程语言的一个例子。SQL 语句不直接描述计算过程，而是描述某个计算期望得到的结果。设计并执行计算过程、产生这一结果，是数据库系统查询解释器（query interpreter）的职责。

这种交互方式与 Python 或 Scheme 的过程式编程范式大不相同。在 Python 中，计算过程由程序员直接描述。声明式语言把过程细节抽象掉，转而关注结果的形式。

## 4.3.1 表

SQL 语言是标准化的，但大多数数据库系统都实现了一些自定义变体，各自带有专有功能。本书描述的是 [Sqlite](https://sqlite.org/index.html) 实现的一个 SQL 小子集。你可以 [下载 Sqlite](http://sqlite.org/download.html) 或使用 [在线 SQL 解释器](https://sql.js.org/examples/GUI/index.html) 跟着一起操作。

一张表也称为关系（relation），它有固定数量的列，每列都有名称和类型。表的每一行代表一条数据记录，每列各有一个值。例如，一张城市表可能有两列存放数字值：经度和纬度，另有一列 `name` 存放字符串。每一行都用经度和纬度值表示一个城市的位置。

| Latitude | Longitude | Name        |
| -------- | --------- | ----------- |
| 38       | 122       | Berkeley    |
| 42       | 71        | Cambridge   |
| 45       | 93        | Minneapolis |

在 SQL 中，可以用 `select` 语句创建一张单行表，行值之间用逗号分隔，列名跟在关键字 **「as」** 后面。所有 SQL 语句都以分号结尾。

```sql
sqlite> select 38 as latitude, 122 as longitude, "Berkeley" as name;
38|122|Berkeley
```

第二行是输出结果，每行对应表的一行，各列之间用竖线分隔。

用 `union` 可以把两张表的行合并起来，构造出多行表。新表沿用左表的列名。一行内多余的空格不影响结果。

```sql
sqlite> select 38 as latitude, 122 as longitude, "Berkeley" as name union
   ...> select 42,             71,               "Cambridge"        union
   ...> select 45,             93,               "Minneapolis";
38|122|Berkeley
42|71|Cambridge
45|93|Minneapolis
```

用 `create table` 语句可以给表命名。这个语句也能用来创建空表，但我们重点关注它给已有表命名的形式，这个已有表由 `select` 语句定义。

```sql
sqlite> create table cities as
   ...>    select 38 as latitude, 122 as longitude, "Berkeley" as name union
   ...>    select 42,             71,               "Cambridge"        union
   ...>    select 45,             93,               "Minneapolis";
```

表一旦有了名字，就可以在 `select` 语句的 `from` 子句中使用这个名字。用特殊的 `select *` 形式可以显示表的所有列。

```sql
sqlite> select * from cities;
38|122|Berkeley
42|71|Cambridge
45|93|Minneapolis
```


## 4.3.2 Select 语句

`select` 语句可以定义一张新表：要么列出单行中的值，要么（更常见）用 `from` 子句对现有表做投影：

`select [column description] from [existing table name]`

结果表的各列由一串逗号分隔的表达式描述，每个表达式都会对现有输入表的每一行求值一次。

例如，我们可以创建一张两列的表，用每个城市相对伯克利偏北或偏南的距离来描述它。每一度纬度相当于向北 60 海里。

```sql
sqlite> select name, 60*abs(latitude-38) from cities;
Berkeley|0
Cambridge|240
Minneapolis|420
```

列描述是某个语言中的表达式，它与 Python 有很多共同点：中缀运算符，如 `+` 和 `%`；内置函数，如 `abs` 和 `round`；以及描述求值顺序的括号。这些表达式中的名称，比如上面的 `latitude`，求值为被投影那一行的列值。

每个表达式后面都可以选择性地跟关键字 `as` 和一个列名。当整张表要被命名时，通常最好给每列起个名字，这样将来就能在 `select` 语句中引用它。由简单名称描述的列会自动命名。

```sql
sqlite> create table distances as
   ...>   select name, 60*abs(latitude-38) as distance from cities;
sqlite> select distance/5, name from distances;
0|Berkeley
48|Cambridge
84|Minneapolis
```

**Where 子句。** `select` 语句还可以包含一个带过滤表达式的 `where` 子句。这个表达式会过滤要投影的行。只有过滤表达式的求值结果为真值的行，才会用来在结果表中生成一行。

```sql
sqlite> create table cold as
   ...>   select name from cities where latitude > 43;
sqlite> select name, "is cold!" from cold;
Minneapolis|is cold!
```

**Order 子句。** `select` 语句还可以对结果表排序。`order` 子句包含一个排序表达式，会对每个未被过滤掉的行求值。该表达式的求值结果用作结果表的排序依据。

```sql
sqlite> select distance, name from distances order by -distance;
84|Minneapolis
48|Cambridge
0|Berkeley
```

把这些特性组合起来，`select` 语句就能把输入表投影成各种各样的相关输出表。
