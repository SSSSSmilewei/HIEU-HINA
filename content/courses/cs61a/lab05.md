## 用官方起始代码在本地做（可选）

1. 下载起始代码 [lab05.zip](https://raw.githubusercontent.com/lr2933/cs61a-spring-2026/HEAD/lab/lab05/lab05.zip)，解压到一个文件夹里。
2. 在这个文件夹里打开终端，补全起始文件里标着 `YOUR CODE HERE` 的部分。
3. 运行 `python3 ok -q 题目名 --local` 测试某一题，运行 `python3 ok --score --local` 查看全部得分。自学者没有伯克利的账号，命令后面要加上 `--local`，也不需要提交。
