## 4.3.3 连接

数据库通常包含多张表，查询可能需要用到不同表中的信息才能算出想要的结果。比如，我们可能有另一张表，描述不同城市的日平均最高气温。

```sql
sqlite> create table temps as
   ...>   select "Berkeley" as city, 68 as temp union
   ...>   select "Chicago"         , 59         union
   ...>   select "Minneapolis"     , 55;
```

把多张表连接（join）成一张表来组合数据，这是数据库系统的基本操作。连接的方法有很多，彼此密切相关，但本书只关注其中一种。连接表时，结果表中会为输入表各行的每一种组合生成一个新行。如果连接两张表，左表有 $m$ 行，右表有 $n$ 行，那么连接后的表就有 $m \cdot n$。在 SQL 中，连接用 `select` 语句的 `from` 子句中以逗号分隔的表名来表示。

```sql
sqlite> select * from cities, temps;
38|122|Berkeley|Berkeley|68
38|122|Berkeley|Chicago|59
38|122|Berkeley|Minneapolis|55
42|71|Cambridge|Berkeley|68
42|71|Cambridge|Chicago|59
42|71|Cambridge|Minneapolis|55
45|93|Minneapolis|Berkeley|68
45|93|Minneapolis|Chicago|59
45|93|Minneapolis|Minneapolis|55
```

连接通常还会搭配一个 `where` 子句，用来表达两张表之间的关系。例如，如果我们想把数据收集到一张表里，以便把纬度和气温关联起来，就要从连接结果中选出两张表都提到同一个城市的那些行。在 `cities` 表中，城市名存放在名为 `name` 的列中；在 `temps` 表中，城市名存放在名为 `city` 的列中。`where` 子句可以选出连接表中这两个值相等的行。在 SQL 中，数值相等用单个 `=` 符号来测试。

```sql
sqlite> select name, latitude, temp from cities, temps where name = city;
Berkeley|38|68
Minneapolis|45|55
```

表可能有重名的列，因此我们需要一种按表名区分列的办法。表也可能和自身连接，因此我们还需要一种区分表的办法。为此，SQL 允许在 `from` 子句里用关键字 `as` 给表起别名，并用点表达式引用某张表中的列。下面的 `select` 语句计算不同城市两两之间的温差。`where` 子句中的字母顺序约束保证每一对城市在结果中只出现一次。

```sql
sqlite> select a.city, b.city, a.temp - b.temp
   ...>        from temps as a, temps as b where a.city < b.city;
Berkeley|Chicago|10
Berkeley|Minneapolis|15
Chicago|Minneapolis|5
```

SQL 中组合表的两种方式，`join` 和 `union`，让这门语言具有很强的表达能力。


## 4.3.4 解释 SQL

要为目前介绍的这部分 SQL 创建一个解释器，我们需要：一个表示表的结构、一个把文本语句解析成可执行代码的解析器，以及一个执行解析后语句的求值器。[sql](https://www.composingprograms.com/examples/sql/sql_exec.py) 解释器示例包含了所有这些组件，演示了一个简单但功能完整的声明式语言解释器。

在这个实现中，每张表都有自己的类，表中的每一行都用它所属表这个类的一个实例来表示。一行中，表的每一列都对应一个属性；而表就是一个行的序列。

表的类是用 Python 标准库 `collections` 包中的 [namedtuple](https://docs.python.org/3/library/collections.html#collections.namedtuple) 函数创建的，该函数返回一个新的元组子类，为元组中的每个元素命名。

考虑上一节的 `cities` 表，下面重复一遍：

```sql
sqlite> create table cities as
   ...>    select 38 as latitude, 122 as longitude, "Berkeley" as name union
   ...>    select 42,             71,               "Cambridge"        union
   ...>    select 45,             93,               "Minneapolis";
```

下面的 Python 语句为这张表构造了一个表示：

```py
>>> from collections import namedtuple
>>> CitiesRow = namedtuple("Row", ["latitude", "longitude", "name"])
>>> cities = [CitiesRow(38, 122, "Berkeley"),
              CitiesRow(42,  71, "Cambridge"),
              CitiesRow(43,  93, "Minneapolis")]
```

用序列操作可以解释 `select` 语句的结果。考虑上一节的 `distances` 表，下面重复一遍：

```sql
sqlite> create table distances as
   ...>   select name, 60*abs(latitude-38) as distance from cities;
sqlite> select distance/5, name from distances;
0|Berkeley
48|Cambridge
84|Minneapolis
```

这张表由 `cities` 表的 `name` 列和 `latitude` 列生成。把函数映射到输入表的各行上，就能生成这张结果表：这个函数对每个 `CitiesRow` 返回一个 `DistancesRow`。

```py
>>> DistancesRow = namedtuple("Row", ["name", "distance"])
>>> def select(cities_row):
        latitude, longitude, name = cities_row
        return DistancesRow(name, 60*abs(latitude-38))
>>> distances = list(map(select, cities))
>>> for row in distances:
        print(row)
Row(name='Berkeley', distance=0)
Row(name='Cambridge', distance=240)
Row(name='Minneapolis', distance=300)
```

我们的 SQL 解释器把这种做法推广开来：一个 `select` 语句表示为 `Select` 类的一个实例，由该语句的各个子句构造而成。

```py
>>> class Select:
        """从 [tables] 中选择 [columns]，满足 [condition]，按 [order] 排序。"""
        def __init__(self, columns, tables, condition, order):
            self.columns = columns
            self.tables = tables
            self.condition = condition
            self.order = order
            self.make_row = create_make_row(self.columns)
        def execute(self, env):
            """把来自各表的行连接、过滤、排序，再映射到列上。"""
            from_rows = join(self.tables, env)
            filtered_rows = filter(self.filter, from_rows)
            ordered_rows = self.sort(filtered_rows)
            return map(self.make_row, ordered_rows)
        def filter(self, row):
            if self.condition:
                return eval(self.condition, row)
            else:
                return True
        def sort(self, rows):
            if self.order:
                return sorted(rows, key=lambda r: eval(self.order, r))
            else:
                return rows
```

`execute` 方法先连接输入表，再过滤和排序得到的行，然后把一个叫 `make_row` 的函数映射到这些行上。`make_row` 函数是在 `Select` 构造函数中调用 `create_make_row` 创建的，它是一个高阶函数，负责为结果表创建新类，并定义如何把输入行投影成输出行。（带更多错误处理和特殊情况处理的版本见 [sql](https://www.composingprograms.com/examples/sql/sql_exec.py)。）

```py
>>> def create_make_row(description):
        """返回一个从输入环境（dict）到一行输出的函数。
        description -- 由 [表达式] as [列名] 组成的逗号分隔列表
        """
        columns = description.split(", ")
        expressions, names = [], []
        for column in columns:
            if " as " in column:
                expression, name = column.split(" as ")
            else:
                expression, name = column, column
            expressions.append(expression)
            names.append(name)
        row = namedtuple("Row", names)
        return lambda env: row(*[eval(e, env) for e in expressions])
```

最后，我们需要定义 `join` 函数来创建输入行。给定一个 `env` 字典，其中以表名为键存放现有表（即行的列表），`join` 函数用 `itertools` 包中的 [product](https://docs.python.org/3/library/itertools.html#itertools.product) 函数把输入表中所有行的组合起来。然后它把一个叫 `make_env` 的函数映射到连接后的行上，这个函数把每一种行组合转换成一个字典，以便用来求值表达式。（带更多错误处理和特殊情况处理的版本见 [sql](https://www.composingprograms.com/examples/sql/sql_exec.py)。）

```py
>>> from itertools import product
>>> def join(tables, env):
        """返回一个迭代器，遍历一行中从名称到值的字典。
        tables -- 逗号分隔的表名序列
        env    -- 从全局名称到表的字典
        """
        names = tables.split(", ")
        joined_rows = product(*[env[name] for name in names])
        return map(lambda rows: make_env(rows, names), joined_rows)
>>> def make_env(rows, names):
        """创建一个把名称绑定到值的环境。"""
        env = dict(zip(names, rows))
        for row in rows:
            for name in row._fields:
                env[name] = getattr(row, name)
        return env
```

上面的代码中，`row._fields` 求值为包含该行的表的列名。之所以存在 `_fields` 属性，是因为 `row` 的类型是一个 `namedtuple` 类。

我们的解释器已经足够完整，可以执行 `select` 语句了。例如，我们可以计算从伯克利到其他所有城市的纬度距离，并按经度排序。

```py
>>> env = {"cities": cities}
>>> select = Select("name, 60*abs(latitude-38) as distance",
                    "cities", "name != 'Berkeley'", "-longitude")
>>> for row in select.execute(env):
        print(row)
Row(name='Minneapolis', distance=300)
Row(name='Cambridge', distance=240)
```

上面的例子等价于下面这条 SQL 语句：

```sql
sqlite> select name, 60*abs(latitude-38) as distance
   ...>        from cities where name != "Berkeley" order by -longitude;
Minneapolis|420
Cambridge|240
```

我们还可以把这张结果表存进环境，再和 `cities` 表连接起来，取出每个城市的经度。

```py
>>> env["distances"] = list(select.execute(env))
>>> joined = Select("cities.name as name, distance, longitude", "cities, distances",
                    "cities.name == distances.name", None)
>>> for row in joined.execute(env):
        print(row)
Row(name='Cambridge', distance=240, longitude=71)
Row(name='Minneapolis', distance=300, longitude=93)
```

上面的例子等价于下面这条 SQL 语句：

```sql
sqlite> select cities.name as name, distance, longitude
   ...>        from cities, distances where cities.name = distances.name;
Cambridge|240|71
Minneapolis|420|93
```

完整的 [sql](https://www.composingprograms.com/examples/sql/sql_exec.py) 示例程序还包含一个简单的 `select` 语句解析器，以及 `create table` 和 `union` 的 `execute` 方法。这个解释器能正确执行前面出现的所有 SQL 语句。虽然这个简单的解释器只实现了完整结构化查询语言的一小部分，但它的结构展示了序列处理操作和查询语言之间的关系。

**查询计划。** 声明式语言描述结果的形式，但不明确描述结果该怎么算出来。这个解释器总是先连接、过滤、排序，再投影输入行，以此算出结果行。不过，算出同一结果可能有更高效的办法，查询解释器可以从中挑选。为查询结果挑选高效的计算过程，是数据库系统的核心特性。

例如，考虑上面的最后一条 `select` 语句。与其先计算 `cities` 和 `distances` 的连接再过滤结果，不如先按 `name` 列对两张表排序，再对排好序的表做一次线性遍历，只连接名称相同的行。当表很大时，查询计划选择带来的效率提升可能相当可观。
