# 第 38 讲：总结

> 本页由海纳协会整理。官方这一讲是全学期的回顾和展望，没有公开的讲义。

## 这门课学了什么

CS61A 的主线是**管理程序的复杂度**，手段是四种抽象：

| 抽象 | 讲次 | 关键概念 |
|---|---|---|
| 函数抽象 | 1–10 | 表达式与环境、高阶函数、`lambda`、递归与树形递归 |
| 数据抽象 | 11–17 | 序列与容器、构造器与选择器、树、可变性、迭代器与生成器 |
| 对象 | 18–24 | 类与实例、属性、继承、特殊方法、链表与 `Tree` 类、效率 |
| 解释器与声明式编程 | 26–35 | Scheme、宏、解释器的结构、SQL |

同时学会了三门语言（Python、Scheme、SQL），并且亲手写了一个 Scheme 解释器——学会一门新语言最好的办法之一，就是理解它的解释器是怎样工作的。

## 接下来学什么

- **CS61B（数据结构）**：用 Java 学习数据结构与算法，写上千行的项目。本站收录了这门课。
- **CS61C（计算机体系结构）**：从 C 语言到 RISC-V 汇编，再到处理器电路，理解程序在机器上怎样运行。本站收录了这门课。
- 也可以按兴趣学习离散数学与概率（CS70）、人工智能（CS188）等课程。

## 期末考试

期末考试覆盖全学期的内容，Scheme、宏、解释器和 SQL 的比重会比期中考试更高。复习方法和期中一样：重做练习、限时做往年试题、整理自己的笔记纸。
