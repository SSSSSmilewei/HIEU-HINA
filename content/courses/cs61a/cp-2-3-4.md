## 2.3.4 序列抽象

我们已经介绍了两种满足序列抽象的原生数据类型：列表（list）和范围（range）。两者都满足本节开头提出的条件：长度和元素选择。Python 的序列类型还有另外两种行为，扩展了序列抽象。

**成员资格**（Membership）：我们可以测试一个值是否属于某个序列。Python 有 `in` 和 `not in` 两个运算符，根据元素是否出现在序列中，求值为 `True` 或 `False`。

```python
>>> digits
[1, 8, 2, 8]
>>> 2 in digits
True
>>> 1828 not in digits
True
```

**切片**（Slicing）：序列内部还含有更小的序列。序列的切片是原序列中任意一段连续的部分，用一对整数指定。和 `range` 构造函数一样，第一个整数是切片的起始索引，第二个是结束索引的后一位。

在 Python 中，序列切片的写法和元素选择类似，也用方括号。冒号分隔起始和结束索引。任意一端省略时，都默认取极值：起始索引默认是 0，结束索引默认是序列的长度。

```python
>>> digits[0:2]
[1, 8]
>>> digits[1:]
[8, 2, 8]
```

列举 Python 序列抽象这些额外行为，正好让我们想一想：一般来说，什么才算有用的数据抽象。抽象的丰富程度（也就是它包含多少行为）是有后果的。对抽象的使用者来说，额外的行为可能很有帮助。但另一方面，用一个新的数据类型去满足丰富抽象的全部要求，可能相当困难。丰富抽象还有一个坏处：使用者要花更长时间去学。

序列之所以有如此丰富的抽象，是因为它们在计算中无处不在，学这少量复杂行为是值得的。一般来说，大多数用户定义的抽象都应该尽量简单。

**拓展材料**：切片符号支持多种特殊情况，例如负的起始值、结束值和步长。在线书籍《Dive Into Python 3》中名为 [列表切片](http://getpython3.com/diveintopython3/native-datatypes.html#slicinglists) 的小节给出了完整的描述。本章我们只会用到上面这些基本特性。


## 2.3.5 字符串

文本值对计算机科学来说，也许比数字还要基础。一个恰当的例证是：Python 程序本身就是以文本形式编写和保存的。Python 里表示文本的原生数据类型叫**字符串**（string），对应构造函数 `str`。

Python 中字符串如何表示、如何书写、如何操作，细节很多。字符串是丰富抽象的又一个例子，程序员得下不少功夫才能掌握。本节只是对字符串核心行为的简要介绍。

**字符串字面量**（string literals）能表示任意文本，用单引号或双引号括起来。

```python
>>> 'I am string!'
'I am string!'
>>> "I've got an apostrophe"
"I've got an apostrophe"
>>> '您好'
'您好'
```

我们在之前的代码里已经见过字符串：文档字符串（docstrings）、`print` 调用中的文本，以及 `assert` 语句中的错误消息。

字符串满足本节开头介绍的**序列**两个基本条件：有长度，也支持元素选择。

```python
>>> city = 'Berkeley'
>>> len(city)
8
>>> city[3]
'k'
```

字符串的元素本身就是只含单个字符的字符串。字符可以是字母表里的任意单个字母、标点符号或其他符号。和许多其他编程语言不同，Python 没有单独的字符类型：任何文本都是字符串，表示单个字符的字符串长度为 1。

和列表一样，字符串也能通过加法和乘法组合。

```python
>>> 'Berkeley' + ', CA'
'Berkeley, CA'
>>> 'Shabu ' * 2
'Shabu Shabu '
```

**成员资格**：字符串的行为和其他序列类型不一样。字符串抽象**并不完全符合**我们为列表和范围描述的通用序列抽象。特别是，成员运算符 `in` 虽然适用于字符串，但行为和应用于序列时完全不同：它匹配的是**子串**，而不是元素。

```python
>>> 'here' in "Where's Waldo?"
True
```

**多行字面量**（Multiline Literals）：字符串不限于一行。三引号可以界定跨多行的字符串字面量。我们在文档字符串里已经大量用过这种三引号。

```python
>>> """The Zen of Python
claims, Readability counts.
Read more: import this."""
'The Zen of Python\nclaims, "Readability counts."\nRead more: import this.'
```

在上面的打印结果中，`\n`（读作「backslash en」）是**代表换行符的单个元素**。虽然它看起来像两个字符（反斜杠和「n」），但计算长度和做元素选择时，它都算作单个字符。

**字符串强制转换**（String Coercion）：在 Python 里，只要调用 `str` 构造函数、把一个对象值当作参数传进去，就能从任何对象造出一个字符串。字符串的这个特性，很适合从各种类型的对象拼出描述性的字符串。

```python
>>> str(2) + ' is an element of ' + str(digits)
'2 is an element of [1, 8, 2, 8]'
```

**拓展材料**：计算机中的文本编码是个复杂的话题。本章我们会忽略字符串底层表示的细节。不过对很多应用来说，了解**计算机如何编码字符串**的细节是必备知识。《Dive Into Python 3》的 [字符串章节](http://getpython3.com/diveintopython3/strings.html) 介绍了字符编码和 Unicode。
